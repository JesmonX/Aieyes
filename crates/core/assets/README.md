# Default desktop pet

`yuexinmiao1.codex-pet.zip` contains the original `pet.json` and `spritesheet.webp`
served by https://codex-pet.org/zh/pets/yuexinmiao1/ (creator: **kiffin**).
The sheet SHA-256 is `4fd7d2ed00b9cce321acba7953ecb25290a78391046e94308c2b8947763c4bcd`.

The application imports this package on first use through the public file importer.
Renderers only use the imported PNG cache. They never load this archive directly.
The original character and artwork remain attributed to their creator.
