# 历史日期范围

主界面与面板保留今日、7/30/90/365 天，增加「所有」和「自定义日期」。选择自定义后填写首尾日期并应用，两端日期均包含，按运行核心的本机时区划分自然日。

`dashboard` 的筛选参数兼容原有 `days`，新增 `dateRange`：

```json
{"provider":"codex","days":7,"dateRange":{"kind":"all"}}
```

```json
{"dateRange":{"kind":"custom","start":"2024-02-28","end":"2024-03-01"}}
```

显式 `dateRange` 优先于 `days`。传 `null` 或省略即可使用旧快捷范围。「所有」从当前 provider/account/source/model 筛选下最早的记录开始，到今天为止；自定义范围的起止日期必须有效且顺序正确。无记录的自然日仍保留在日期序列中。

新范围同时作用于总量、趋势、模型分布、每日明细和热力图。跨年热力图按年展开，默认只创建最近年份；Web 每日表每次加载 31 天。旧快捷范围保持至少七天趋势与过去 365 天热力图的原有行为。`dashboard.summary` 仍用于无筛选今日菜单摘要，不随历史范围变化。

日期筛选在当前设备保存；打开独立详情时会传递 `dateRange`。核心复用日聚合缓存，按日期读取时检查取消信号。
