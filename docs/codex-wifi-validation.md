日志的创建者只记录一次，恢复同一会话不会改变创建者；`token_usage_record` 和 `turn_context` 没有逐请求账户标识。不能把所有后续用量都给创建者，也不能因缺口两端身份相同就假定中间没有切换。

## 修复与恢复边界

- 普通额度查询新增查询前后实际日常登录身份的哈希观测。查询非当前账户档案时，也记录日常账户，而不是被查询的档案。Rust 本机与 Python SSH 同步实现。
- 观测在来源配置、切换代次和身份一致性校验后保存；A→B→A 的旧查询不得补入伪造的稳定区间。迟到观测不能倒插切换边界。
- 拒绝原因细分为身份不一致、观测超过五分钟、跨切换/不确定区间，诊断输出观测缺口及指纹候选。
- 历史回放只使用已存证据，核验相关设备在当时的覆盖，跳过重叠的已保存可靠片段。共享事件、原采样、冻结价格和实时基线不改写。
