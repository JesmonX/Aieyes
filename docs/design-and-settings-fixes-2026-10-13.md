# 设计、设置页与宠物修复计划

2026-10-13，经逐项决策确认。账户与数据源的解除关联、重新分配本轮暂缓。macOS 与 Windows/Linux 保持相同的核心行为。

## 机器绑定与采集调度

- 删除 SSH 主机时，关联目录进入“机器未绑定”状态，保留原机器标识、目录、账户关系及历史。启用本机或 Agent 都不能重新激活这些目录。
- 增加 `sources.rebind`，显式选择目标机器，检查配置冲突和重复目录。受管理的 Codex 目录验证原 home 身份，不能借重绑改变账户关联。重绑清理旧采集游标和估值基线，保留历史。
- 本机和 SSH 均提供资源监控控制，以及独立的暂停整机采集操作。资源监控只控制资源指标；整机暂停覆盖历史、额度、会话和自动估值。
- 全局及账户额度间隔统一为 5–86400 秒，账户留空继承全局。下次自动查询从上次查询结束开始计时，失败也遵守间隔，不补跑积压任务。
- 同一数据目录的所有核心进程间最多四个账户并发。每账户最多一个在途查询，按到期顺序公平调度，同一实际登录目录互斥。
- 定时、手动和估值查询共用账户及目录协调，合并重复请求；手动采样边界必须获取满足采样时序的新快照。每账户完成后立即保存、发布结果，不等待慢账户。
- 额度与历史独立调度，复用来源锁和短数据库事务。停用、配置改变、休眠恢复或进程退出后重新检查任务资格。
- 新增绑定状态、SSH 资源监控开关和本机整机启用字段。旧配置保留原启停效果，不凭目录猜测机器归属。

## 会话接入、宠物与性能

### Hook 接入

SSH 上 Codex 使用日志；Claude、AGY 在采集时自动部署观察 hook，需要 SSH 和 Python 3，不安装常驻服务。

- 机器行显示接入状态，点击进入设置，多目录分别显示和操作。
- Claude、AGY 提供自动接入开关、修复及停用。停用不被轮询重新安装，日志回退仍工作。Codex 仅显示日志接入状态。
- 状态行复用会话健康缓存，不因进入设置串行扫描全部 SSH 主机。只管理 Aieyes 自有 hook，保留其他配置。

### 多会话宠物

- 保留一个宠物。优先级：等待输入 → 失败 → 工作/思考/工具 → 完成/中断 → 待确认；同级选最近更新会话。
- 核心输出 `activeCount` 和 `phaseCounts`。多会话文字条显示各状态数量，如 `等待1 · 工作2 · 思考1`。长文字换行并调整窗口边界，避免裁切。
- 等待输入计入活跃数；完成、失败、中断不计入。来源故障独立提示。

| 状态 | 动作 |
| --- | --- |
| 空闲 | 待机 |
| 工作 | 向右跑 |
| 思考 | 检查/思考 |
| 执行工具 | 原地跑 |
| 等待输入 | 挥手 |
| 完成 | 跳跃 |
| 失败 | 失败动作 |
| 中断 | 向左撤回 |
| 待确认 | 等待动作 |

按追加决定，每帧改为 100 毫秒（10 fps），当前状态持续循环，支持减少动态效果。数量变化不重启动画，兼容 v1/v2 宠物包。

### 图像边缘与缩放（追加）

- 检查 macOS、Windows 原生绘制与 Linux/Web 桌面端在深浅背景、不同缩放下的透明边缘，区分素材本身的描边和渲染引入的黑白边。修复透明度、插值或图集相邻帧采样问题，保留原素材配色。
- 桌面端下方状态栏统一使用圆角；Windows 采用带抗锯齿的圆角路径，保留透明窗口与高对比度支持。
- 设置中增加桌宠缩放滑块，范围 50%–200%，默认 100%，可一键恢复。比例按设备保存；图像、状态条、点击区域和窗口边界一起缩放，独立于显示器 DPI 与面板大小。
- 调整比例后立即预览并将窗口约束在可见屏幕内；重启、切换宠物及多会话换行后保留比例。验证小数比例、跨 DPI 和 10 fps 播放。

### 右键菜单

已复现：`NSHostingView` 自动菜单校验禁用两个自定义动作。关闭该菜单的自动校验并显式管理启用状态，保留有效动作目标。“打开面板”只打开，已打开时不关闭；左键保留原切换行为。“隐藏宠物”保存隐藏状态并更新窗口，设置中可恢复。

### 设置页性能

合成基线：Web 1,000 个模型渲染/布局约 232 毫秒；10 账户 × 3 目录刷新会整页重建 32 次，约 380 毫秒。这不是用户实机完整应用耗时。

- macOS 设置仅观察所需投影，隔离会话、宠物高频状态，相同内容不重复发布。
- 账户状态按标识更新对应行，合并连续通知，保留焦点、草稿和滚动。
- 折叠内容展开才创建；估值记录按相关数据变化刷新，不跟随每次概览生成时间。
- 额度逐项结果只更新对应账户，不引起整页重建。
- 同机目标：1,000 模型热切换 P95 < 100 毫秒；设备状态刷新不再整页重建设置。
