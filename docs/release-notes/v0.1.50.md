## 更新范围

本次更新覆盖 **v0.1.49 → v0.1.50**，优化日常刷新、主机监控和会话观察的性能，统一 Web 与 macOS 的 Agent 设置，并修复 Windows 共享检查中的跨平台管道测试。

## 运行时性能

- 仪表盘按设置、用量、价格和状态修订复用快照；仅额度、估值或来源状态变化时使用轻量状态更新，减少历史用量重读。Web 刷新合并重复请求，并在繁忙操作完成后恢复刷新。
- 主机监控使用常驻调度器，本机与远程采样分开执行；慢主机不再阻塞其他主机刷新，配置变更、暂停和退出会取消旧任务，过期结果不会覆盖新配置。
- 缓存已解码的设置、价格和日聚合，估值摘要通过索引选取最新记录及有效值；额度协调和自动采样只读取未完成记录，减少已完成历史的重复处理。
- 会话文件确认读到末尾后复用缓存，目录发现使用文件监听并保留监听不可用时的轮询回退；SSH 复用观察进程，保留半行续读、文件轮转和增量游标处理。
- 按代理与连接策略复用 HTTP 客户端，macOS 观察系统代理变化；Swift 长寿命 IPC 读取循环及时释放临时对象。Windows 桌宠按实际下一帧调度，隐藏或减少动态效果时停止动画计时。

## Agent 与账户设置

- Web 与 macOS 按统一的能力定义显示账户、API、机器与目录及估值入口，合并 DeepSeek 的可见设置分组，同时保留底层来源和账户标识。
- 账户表单按提供商及模式显示支持的字段，单一模式省略选择器，切换模式时同步调整工作区和本地登录选项。
- 更新提供商图标及深浅色资源，统一设置与配置向导中的展示。

## 修复与验证

- 修复 Windows 子进程管道回归测试使用 `select()` 导致的 `WinError 10038`；改用线程和队列读取，保留响应超时、连续请求和 EOF 退出检查。
- 发布准备前，核心四平台、macOS 原生以及 Windows/Linux 桌面 CI 全部通过；Windows 共享检查、浏览器集成、桌面测试与安装包构建已通过修复后的远端验证。
- 性能对照使用隔离数据、合成负载和模拟 SSH；本地长测主要覆盖背景运行，不能据此宣称所有真实网络场景具有相同收益或整应用无内存泄漏。
