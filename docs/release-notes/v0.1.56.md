## 更新范围

本次更新覆盖 **v0.1.54 → v0.1.56**，将精确计数扩展为所有 Agent 共用的设置，完善原生历史与会话状态，修复 Qoder 同步及 Linux 桌面交互，并更新中英文界面和官网资源。

## 共享精确计数

- 「刷新与历史」中的精确计数开关统一控制各 Agent：开启时排除可确认的继承历史，关闭时恢复原始用量；独立子任务产生的新请求继续计入，重复导入和镜像记录仍正常去重。
- 新安装默认开启，已有安装升级时统一开启一次，之后保留用户选择。兼容旧设置，切换后在下次同步重算统计。
- 保留原始计量、账户归属和首次价格，切换模式不按当前价格重算旧成本；已保存的继承记录可在原文件缺失时恢复。首次修正历史前创建独立备份，快速切换设置时阻止旧同步结果覆盖新选择。
- 补齐 Codex、Claude Code、Kimi、OpenCode、CodeBuddy、Pi、Oh My Pi、DeepSeek Harness 等来源的继承依据与去重处理。本机与 SSH 使用一致的计数规则。

## Agent 历史与会话

- OpenCode 同时支持 v1 与 v2 历史，分别保存读取进度，识别压缩摘要用量、工具调用和结束状态。改进 Pi、Oh My Pi、Harness 的历史身份、压缩记录及增量追加处理。
- CodeBuddy 增加原生监测 Hook 的安装、停用与修复入口，保留其他 Hook；修正缓存分类、并行工具计量、中间回答误判完成及取消后误判成功的问题。
- 改进 Kimi 模型归属、权限等待与交互结束识别，补齐 Grok 工具和权限事件。根据原生时间和轮次判断状态，更新标题不会让旧会话重新活跃。
- 有明确关系的子会话归并到主会话，列表、数量、摘要和桌宠保持一致；等待状态汇总到主会话，子任务失败不直接将主会话标记为失败，实际用量继续保留。
- 历史文件原地替换、损坏行、超大记录和压缩损坏保留诊断与重试位置，其他会话可继续导入。修复 Windows 路径与换行下的历史游标回归断言，并同时覆盖 LF 与 CRLF。

## Qoder 同步

- 本机与 SSH 兼容保留大小写及小写的项目路径哈希，按解密认证结果选择正确状态文件；修正加密历史残差计算，避免重新计入已排除的继承用量。
- 额度查询等待初始化完成，并只接受匹配请求和账户的响应。临时断流、超时和额度暂不可用可在总时间限制内重试一次，失败时保留上次成功的额度与时间。

## Linux 桌面

- 修复 AppImage 在部分宿主环境中无法显示托盘的问题；检测托盘服务失效并恢复当前菜单状态，隐藏桌宠后后台刷新不会覆盖「显示桌宠」操作。
- Esc 按菜单、弹窗、面板的层级处理；修复从托盘打开面板或详情窗口时的键盘焦点，以及「桌宠设置」跳转位置。设置入口修复也适用于 Windows。
- Linux 主界面、面板、原生桌宠与 GTK 菜单使用内置鸿蒙字体，保留系统字号和回退字体；字体文件与许可随应用打包。

## 中英文界面与官网资源

- 精简英文导航、操作和指标文案，改善窄窗口与紧凑面板布局；macOS 面板内容跟随可用宽度，英文额度刷新按钮保持单行。
- 更新中英文官网内容、字体和图标，补齐两种语言、macOS/Windows 各页面的展示图；桌宠动画使用有效帧，并遵循减少动态效果的系统偏好。
- 官网源码增加六种安装包的直接下载入口和随最新正式版本解析的下载路由，完善移动端、无 JavaScript 与下载失败页面。

## 构建与发布

- 修复 Ubuntu 22.04 对 RPM 包的读取兼容性，继续完整检查安装包中的程序、字体、启动项及图标。
- 让数据库增量读取测试使用明确递增的文件时间戳，避免快速连续写入导致 CI 偶发误判未更新。

## English

This release adds a shared precise-counting setting across Agents, with reversible handling of verified inherited history and preserved historical prices. It improves native history imports, parent and child session grouping, CodeBuddy monitoring, and Qoder history and quota synchronization. Linux gains tray recovery, corrected Escape and focus behavior, and bundled HarmonyOS fonts. English and Chinese layouts, website resources, screenshots, and installer download routes are also updated.
