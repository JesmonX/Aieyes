## 更新范围

本次更新覆盖上一公开版本 **v0.1.45 → v0.1.46** 的全部改动，精简主窗口与浮窗的用量展示，优化 Agent 图标、导航和 Windows 浅色外观，并补充账户额度查询失败的处理入口。

## 总览与用量分析

- 主窗口总览和浮窗的用量摘要固定显示今日，数字继续跟随所选 Agent 和账户；升级后清除这两个页面遗留的日期、来源及模型限制，避免隐藏筛选影响结果。
- 总览和浮窗不再重复显示筛选提示行。用量分析保留独立的 Agent、账户、来源、模型和日期范围，页面切换与“查看分析”继续保持各自的筛选规则。
- 趋势悬停和键盘聚焦读数使用 K／M／B 缩略 Token，成本显示两位小数；精确详情和计算数据保留原精度。
- 用量摘要中的“计价未完成”改为感叹号，通过悬停或键盘聚焦查看说明，点击仍可进入模型价格设置。修复快速切换焦点时提示气泡被旧隐藏计时器关闭的问题。

## Agent 图标、导航与设置

- Cursor、Grok、ZCode 换用官方透明独立标志，单色图标适配浅深色主题；Qoder、OpenCode 保留现有图标。自定义和未知 Agent 的终端图形缩小，保留一致的图标占位。
- 点击侧栏的 Aieyes 眼睛即可收缩或展开导航，移除独立按钮，收缩后仍可操作并记住状态。
- 设置中的入口简写为“配置向导”，移除附带小字。
- 定时唤醒说明追加“可用于帮助规划 5h 重置时间”，设置页和配置向导同步更新。
- Windows 浅色不透明窗口采用浅灰底与白色卡片，改善灰浊感和表面层次；浅深色共用布局、字体和控件尺寸，保留原生材质及无障碍降级路径。

## 额度查询失败提示

- Agent 分组仅统计实际查询失败的账户，额度较高、耗尽或余额不足不再混入失败数量。
- 点击失败数量可查看具体账户和失败原因，并单独重试或进入该账户设置；浮窗仅统计当前显示范围内的账户。
- 后台更新同步刷新失败列表与数量，保留展开状态、滚动位置和键盘焦点；恢复后及时清除提示，错误文本继续执行凭据遮蔽。
