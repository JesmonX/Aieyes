## 中文

本次更新覆盖 `v0.2.14` 到 `v0.2.15`。

- **扩展桌宠会话交互**：在三端支持更完整的审批、文件差异、计划预览与 MCP 表单交互卡片，覆盖 Claude / Qoder、Codex / ChatGPT Work（本机与 SSH）、本机 OpenCode 及 CodeBuddy / ZCode；支持多请求切换，并可在进行中的本机会话发送后续指令或中断当前轮次。
- **滚动估值历史与账户感知圆环**：估值详情新增最近 90 天滚动估值趋势图，可切换 5h、7d 直接估值、7d 容量推算及每 1000 credits 视图；桌宠 Agent 圆环改为优先显示当前活跃会话所属的订阅账户并标明账户信息。
- **超大 JSONL 记录流式解析**：本地与 SSH 用量同步、Codex 继承历史前缀校验（含 `.jsonl.zst`）及实时会话监控对超过 16 MiB（以及 Kimi / DeepSeek Harness 超过 8 MiB）的合法单行记录改用流式元数据投影，不再因单条超大日志卡死在重试位置或阻塞后续统计与会话状态更新。

## English

This release covers `v0.2.14` through `v0.2.15`.

- **Expanded desktop pet session interactions**: Added richer approval, file-diff, plan-preview, and MCP form cards across macOS, Windows, and Linux for Claude / Qoder, Codex / ChatGPT Work (local and SSH), local OpenCode, and CodeBuddy / ZCode, including queued request switching plus follow-up and turn-interrupt actions for active local sessions.
- **Rolling valuation history and account-aware pet rings**: Added a 90-day rolling valuation history chart in estimate details (5h, direct 7d, capacity-scaled 7d, and per-1000-credits views), and updated desktop pet agent rings to track the active session's identified subscription account with account tooltips.
- **Streaming projection for oversized JSONL records**: Local and SSH history sync, Codex inherited-history prefix verification (including `.jsonl.zst`), and live session monitors now stream-project valid JSONL lines larger than 16 MiB (and >8 MiB for Kimi / DeepSeek Harness) in bounded memory instead of getting stuck at a retry position and blocking subsequent usage or session updates.
