## Qoder credit cards and model pricing

Changes since v0.1.69:

- Show Qoder and Qoder CN balances as remaining / total Credits, remove the duplicate remaining line and account ID, and display public subscription names such as Pro. Place the credit buckets side by side to reduce card height on macOS and desktop Web surfaces.
- Separate Gemini 4 Argon valuation from Gemini Models, including Argon's independent weekly quota. Repair affected historical estimates using their original price evidence while retaining the original records.
- Search model prices with multiple keywords in any order, ignoring case and common separators. Queries such as `qwen flash` now match `qwen3.8-flash`.
- Remove resolved models from the unpriced list immediately after saving a mapping, preserve entries that still lack required prices, and use the latest mapping target when editing a remaining entry.

## 中文

相较 v0.1.69：

- Qoder 与 Qoder CN 余额统一显示为“剩余量 / 总量 Credits”，去除重复的剩余文本与账户 ID，订阅显示 Pro 等公开名称；macOS 原生与桌面 Web 卡片的两个 Credits 并排展示，缩小卡片高度。
- 将 Gemini 4 Argon 与 Gemini Models 的估值隔离，支持 Argon 独立的周额度；按原价格证据修正受影响的历史估值，并保留原记录。
- 模型价格支持多关键词、不同顺序、忽略大小写及常见分隔符搜索，输入 `qwen flash` 即可匹配 `qwen3.8-flash`。
- 保存有效映射后，待计价列表立即移除已补齐的模型；仍缺必要价格的条目继续保留，编辑时使用最新映射目标。
