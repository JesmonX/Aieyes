## 更新范围

本次更新覆盖上一公开版本 **v0.1.34 → v0.1.35** 的全部改动，包括桌宠、会话监测、Codex API、估值与历史修正、设置和账户流程、定时唤醒。

## 桌面宠物与文件导入

- macOS、Windows、Linux 统一采用随 Agent 会话状态变化的动画桌宠。首次离线导入随应用附带的月薪喵（作者 kiffin），可在「设置 → 常规 → 桌面显示」导入自己的桌宠。
- 支持 ZIP／`.codex-pet.zip` 或已解压的 `pet.json`，兼容 PNG／WebP、v1 8×9 和 v2 8×11 图集及等比例缩放。导入时校验文件、路径和图集；取消或失败保留原桌宠，成功导入的选择跨重启和升级保留。
- 桌宠支持单击展开面板、拖动并保存位置、菜单进入设置或隐藏；可切换菜单栏／系统托盘。旧悬浮入口偏好迁移到桌宠，无可用托盘时保留可操作的桌面入口。
- 统一三端状态颜色、动画、提示文字和活跃会话计数，遵循系统「减少动态效果」。修复 macOS 面板打开时点击桌宠无法正确切换、桌宠被误判为外部点击等交互问题，并补充 Windows 原生桌宠焦点与面板操作验证。
- 所有桌宠动作统一为每帧 180 毫秒（约 5.6 fps），修复月薪喵捂嘴待机动作过慢的问题。取消活动动画三轮后强制切回待机，让三端图片与下方文字持续反映同一个会话状态。

## Codex、Claude Code 与 AGY 会话监测

- 监测范围从本机 Codex 扩展到已启用的本机及 SSH 机器上的 Codex、Claude Code、AGY（Antigravity CLI）。列表显示 Agent、机器、来源及更新时间，同一目录关联多个账户时不重复计数。
- 本机约每秒更新已有会话、每 5 秒发现新会话；SSH 机器独立后台更新并缓存状态，一台机器超时或离线不会阻塞其他来源，离线缓存附带故障提示。
- 会话状态与历史同步、限额查询分别刷新；进一步拆开 macOS 的刷新调度，启动加载历史、保存设置和重算价格时，桌宠动作与状态仍能独立更新。
- Codex 跟踪轮次及工具输入等待；Claude Code 和 AGY 自动接入生命周期观察 hooks，并结合已有日志或 AGY 会话数据库恢复状态。可在对应 Agent 的「机器与目录」查看、修复或停用接入，保留其他 hooks 和配置。
- 区分等待输入／权限、思考／执行工具、完成、中断、失败和待确认。等待会话计入活跃数；可恢复的工具错误和 AGY 后台任务不会被误判为整轮失败或完成，其他来源故障不会覆盖已知正常状态。
- 观察器只记录必要的生命周期元数据；改进失联、旧会话过期、并行等待解除和数据库连接释放，减少错误状态与资源占用。

## Codex API 接入与账号切换

- 在「设置 → Agent 接入 → Codex」集中管理订阅账号和兼容 Responses API 的连接，支持本机与已配置的 SSH 设备。API 表单只需保存位置、名称、Base URL 和 API Key，沿用 Codex 当前模型、推理强度和网络设置。
- API 与订阅账号共用 Codex home 和对话历史。保存连接不立即改变登录方式；选择「切换到此 API」或「切换到已保存账号」后，先检查并列出受影响进程，确认后再切换，重新打开 Codex 可恢复原对话。
- 改进使用默认 provider 的进程识别，保留明确使用独立 API profile/provider 的实例和辅助进程。配置、凭据或进程在预检后发生变化时要求重新检查；写入失败回滚，切换成功后的刷新失败单独提示。
- API Key 保存在目标设备的私有文件中，编辑留空可保留原密钥，界面和公开设置不回传密钥。API 使用原生 provider 与凭据助手，新连接无需部署计量网关或系统后台任务，关闭 Aieyes 后仍可使用。
- 提供连接测试、修订状态和删除检查；正在使用的连接须先切换并退出对应会话再移除。连接清理保留对话历史、历史用量及旧计量账本。

## 自动估值与 fork 历史修正

- 自动估值依据原生请求增量、额度响应和实际推理路由归因，不再要求选择「纯订阅／混用」模式。同一会话中途切换 API 或订阅时，按实际请求区分，排除已确认的 API 用量。
- 分别识别订阅额度和 credits 的可靠消耗；混合消耗、未知路由、缺失价格、跨边界累计量或缺失父历史等不可靠区间跳过，并保留最后有效结果。
- 自动与手动采样均允许任意正向、价格完整且结果有限的可靠样本立即显示。5 个百分点／5 credits 改为小样本提示，计算使用累计等价成本除以累计消耗。
- 5h、7d 和 credits 分别保留待配对用量，额度计数暂未变化时等待首次正向变化；重置、充值、身份变化或数据缺口会重新建立基线。容忍固定周期重置时间的小幅抖动，新鲜快照可立即推进估值。
- 修复 fork 对话把父会话累计 Token 再次计入的问题：按父历史的精确字节边界处理归档、跨日期及多级 fork；父会话之后的增长不影响子会话，缺失或不完整的父记录恢复后重新校验。本机与 SSH 导入同步支持。
- 首次修复已有 Codex 数据前创建数据库备份，保留原始日志、来源关系、冻结价格及审计记录。允许修正旧累计量并防止旧结果重放，按原采样区间与价格重算受影响估值；无法可靠重算的旧值退出有效估值。

## 设置、账户与面板体验

- 设置整合为「Agent 接入、服务器、价格、定时唤醒、常规」五个分类。按 Agent 集中显示账户、API、机器和目录；常规细分为外观、桌面显示、网络代理、刷新与历史、更新。
- 改进从额度卡片、面板和服务器入口直达对应设置，补充键盘导航与小窗口适配；切换设置页、保存失败和并发编辑时保护表单草稿，独立保存互不干扰。
- 账户状态先展示缓存再后台检查，支持失败重试，区分「已登录设备」与「使用中设备」。每个 Agent 最多显示 5 个账户，超限明确提示；单账户默认展开，多账户默认折叠，并保留手动展开偏好。
- 补充缓存命中率、5h／7d 等价估值的说明，改进无额度快照时已有采样和历史的访问，统一菜单栏、桌宠与悬浮面板的状态和显示行为。

## 定时唤醒与部署可靠性

- Codex 唤醒使用隔离的临时会话执行，协调当前账号凭据读取与续期；账号身份变化时停止本次任务，避免与日常 Codex 会话的凭据操作冲突。
- 运行记录显示更具体的失败原因，包括登录、身份、前置命令、网络超时、CLI 不兼容、文件缺失和权限问题，便于定位及重试。
- 发现任务文件、执行器或系统注册缺失时提供「重新部署」，避免继续显示为可运行；远程部署增加回读验证与失败回滚，macOS 已正常注册且内容未变的任务避免重复注册。
- SSH 唤醒请求改为通过标准输入传输，修复脚本和初始化配置过长导致的命令参数限制问题。

## 跨平台构建与回归

- 修正 Windows 上测试辅助代码的编译条件，完善 LF／CRLF 和中文 fork 日志的精确字节边界验证，并及时释放历史索引及测试数据库连接。
- 修复 Linux 原生进程回归中临时可执行文件偶发无法启动的问题，保留进程身份识别、API 实例保护和账号切换检查。
- 修正历史估值回归测试恰好落在实时快照过期边界时的偶发失败。
