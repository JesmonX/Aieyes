## 更新范围

本次更新覆盖上一公开版本 **v0.1.36 → v0.1.37** 的全部改动，重点修复桌宠动画停顿、缩放后的状态文字，以及服务器资源监控与 Agent 采集开关相互影响的问题。

## 桌宠动画与状态文字

- 保持每帧 100 毫秒（10 fps）的统一节奏。状态轮询和会话数量变化不再反复重建动画定时器，减少动画停顿；仅在帧号变化时更新图片，继续遵循系统减少动态效果设置。
- macOS 拖动改用非阻塞鼠标事件，拖动时动画继续播放；状态文字按最终字号排版，改善桌宠缩放后的清晰度。
- Windows 复用透明窗口绘制缓冲区，缓存状态文字和圆角背景；以三倍物理分辨率绘制后采样并合成，改善不同 DPI 与缩放比例下的文字边缘，并补齐“恢复中”状态提示。
- Web 调整状态条居中方式，减少文字落在小数像素位置造成的模糊；动画使用持续帧回调，跳过没有变化的绘制。

## 资源监控与 Agent 采集

- 服务器设置为本机及每台 SSH 主机提供独立的“资源监控”和“Agent 采集”开关：关闭 Agent 采集仍可查看 CPU、内存等资源指标，关闭资源监控也不影响 Agent 采集。保存失败恢复已保存状态。
- 关闭 Agent 采集的机器从 Agent 接入的“机器与目录”列表隐藏，目录、原有机器选择、账户关联和历史继续保留；重新开启后恢复显示。隐藏期间修改其他机器不会丢失原选择，未绑定机器仍保留修复入口。
- 配置迁移至版本 9，保留旧版本实际生效的资源监控状态，避免升级后意外启动此前暂停的监控。
