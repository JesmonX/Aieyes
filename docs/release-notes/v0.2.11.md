## Desktop pet and model pricing

- Quit Aieyes from the desktop pet’s context menu using the same quit behavior as the menu bar or tray.
- View active Agents around the pet and open their session and quota details.
- Keep OpenRouter prices up to date with background sync. Gemini usage with a recognized effort suffix can use the base model’s price when the original ID has no price or mapping.
