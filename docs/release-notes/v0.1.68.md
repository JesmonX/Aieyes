## Native accounts, quotas and session tracking

Changes since v0.1.67:

- Expand native account discovery, usage imports and quota support across coding agents, including Copilot, Cline, Kilo, Kiro, Roo, Trae, WorkBuddy and Oh My Pi. Available quota fields depend on the client, credentials and subscription; Roo provides history and session tracking without a quota API.
- Discover account changes at startup, after credential or SQLite WAL changes, and over SSH. Keep previous accounts and successful quota snapshots when credentials expire or a refresh fails. Identify shared upstream subscriptions to avoid duplicate quota queries.
- Show ChatGPT Work sessions and usage separately from Codex while sharing their account and quota. Preserve source attribution through session forks and history filters.
- Add Qoder CN as a separate agent with its own native login, directories and account identity. Improve Qoder CLI and desktop usage imports, cumulative-token reconciliation and login-dialog reopening.
- Improve interactive and headless session detection using process evidence and native task records, including internal tasks, forks and sessions written at process exit. Make repeated history imports more reliable.
- Improve native credential and quota handling for Claude Code, Antigravity CLI/IDE, DeepSeek Harness, ZCode and Grok. Add optional Buddy balance login and clearer handling of unknown usage, expired credentials and retained snapshots.
- Fix Windows path handling, SQLite URI handling and cross-platform session/account fixtures. Update account discovery, settings and quota displays on macOS and desktop clients.

Some provider logins, paid plans and protected IDE credentials still require verification with real accounts. Client-specific support and limits are recorded in [agent integration results](https://github.com/JesmonX/Aieyes/blob/v0.1.68/docs/agent-expansion-implementation-results.md) and [Qoder integration notes](https://github.com/JesmonX/Aieyes/blob/v0.1.68/docs/qoder-usage.md).

## 中文

相较 v0.1.67：

- 扩展多种编程 Agent 的原生账号发现、历史用量导入和额度接入，涵盖 Copilot、Cline、Kilo、Kiro、Roo、Trae、WorkBuddy、Oh My Pi 等。可用额度项取决于客户端、登录凭据与套餐；Roo 提供历史与会话跟踪，不提供额度查询。
- 支持启动、凭据或 SQLite WAL 变化及 SSH 场景下的账号发现；账号过期或刷新失败时保留历史账号与成功快照，识别共享上游订阅以减少重复查询。
- ChatGPT Work 的会话和用量可与 Codex 分开筛选，账号与额度保持共享；改进 fork 来源继承和历史归属。
- 新增独立 Qoder CN Agent，分别使用原生登录、目录和账号身份；改进 Qoder CLI/桌面历史导入、累计 Token 补偿及登录弹窗重开。
- 结合真实进程证据和原生任务记录改进交互、无头及内部会话识别，覆盖 fork、子任务和退出时才落盘的记录，并提高重复导入的稳定性。
- 改进 Claude Code、Antigravity CLI/IDE、DeepSeek Harness、ZCode、Grok 的原生凭据与额度处理；增加可选 Buddy 余额登录，明确未知用量、凭据过期和保留快照的显示。
- 修复 Windows 路径、SQLite URI 和跨平台会话/账号回归夹具，完善 macOS 与桌面客户端的账号发现、设置和额度界面。

部分服务商登录、付费套餐和受保护 IDE 凭据仍需真实账号验证。各客户端的支持范围和限制见[接入实施结果](https://github.com/JesmonX/Aieyes/blob/v0.1.68/docs/agent-expansion-implementation-results.md)及 [Qoder 接入说明](https://github.com/JesmonX/Aieyes/blob/v0.1.68/docs/qoder-usage.md)。
