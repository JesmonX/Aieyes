## Windows 面板与界面改进

- 修复胶囊面板点击外部不收起的问题；统一原生窗口显隐，避免收起后仍残留窗口、拦截鼠标操作。
- 展开面板不抢当前应用焦点，点击面板后可使用键盘；固定、菜单与重建操作增加时序保护。
- 每日用量只显示图下一处读数，消除系统提示与自定义提示重复；图例支持折叠，统计指标使用分段选择。
- 以当前 mac 界面为基准调整桌面端字体族、字号、卡片、筛选器、设置分类、账户标签与文案，保留 Windows 侧栏、窗口按钮和胶囊入口。
- 新增 Windows 浏览器截图、实际字体报告和原生面板自动回归；mac 与 Web 对照使用同一组模拟数据。

mac 原生界面保持现状。Windows 字体采用当地系统字体匹配观感，不分发 mac 系统字体。Linux 同步共享 Web 样式调整。
