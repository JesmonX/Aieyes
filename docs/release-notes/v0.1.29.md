## 性能与刷新

- 历史统计增加每日聚合缓存和独立查询通道，重复切换时间范围更快；远程日志支持增量传输、中断续传和事务去重。
- 服务器并行采样并逐台展示结果；桌面复用服务器卡片和可视设备列表，macOS 按需加载设备详情。
- 分别配置 Agent 限额、历史记录、服务器前台和后台刷新间隔，按任务到期时间调度。

## 监测与账户

- 增加本机 CPU、内存、Swap、磁盘、网络与运行时间监测，改进默认文件系统选择。
- Antigravity 支持登录检查与授权、邮箱和订阅识别；导入失败保留有效记录并显示具体原因。
- 改进 Codex 运行进程的账号识别与切换保护，远程助手兼容旧版 Python 的 TOML 解析。绑定登录档案直接读取身份信息，避免被无关的进程查询阻塞。Linux 使用内核启动时钟判断运行实例的配置，避免秒级时间精度造成误判。

## 窗口与更新

- macOS 打开独立窗口时显示程序坞图标，全部关闭后恢复菜单栏运行。
- 更新前等待正在进行的数据和账户任务，保护未保存编辑；取消或失败后恢复刷新。
