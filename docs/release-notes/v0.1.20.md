## Codex 查询兼容性与错误提示

- 修复部分旧版 Codex CLI 因不支持 `--stdio` 参数而提前退出的问题，本地、SSH 查询及远程唤醒能力检查统一使用默认 stdio 启动方式。
- 兼容旧版限额接口的空参数协议，收到明确的参数格式错误时自动重试一次。
- 查询失败显示本地／SSH 位置、初始化／读取限额等阶段、进程退出码与 RPC 错误码，并识别登录、配置、网络和代理问题。

## macOS 性能与更新

- 价格列表按需加载并缓存搜索结果，独立读取价格，减少扫描或远程查询对价格页的阻塞。
- 更新清单和安装包遵循已保存的应用代理，加入限时、有限重试及取消；保持 Sparkle 签名校验。
- 隔离面板底色与动态内容的重绘，合并菜单栏更新，并在窗口不可见时停止不必要的动画和定时刷新。

Codex 兼容性已使用 0.114.0 与 0.160.1 的隔离配置验证；特定机器的登录、代理或 SSH 环境问题需根据新的错误提示排查。面板间歇性竖线问题仍需持续实机观察。
