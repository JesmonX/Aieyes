## macOS sidebar toggle fix

Changes since v0.1.73:

- Fix duplicate sidebar buttons in the macOS toolbar. A single toggle remains available when the sidebar is hidden, including when the eye button's compact navigation mode and the toolbar toggle are used in quick succession.
- Extend native navigation regression checks to cover a single visible toolbar toggle, hiding and restoring the sidebar, and preserving compact navigation at regular and minimum window widths.
