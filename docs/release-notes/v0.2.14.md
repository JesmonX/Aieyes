## 中文

本次更新覆盖 `v0.2.12` 到 `v0.2.14`。

- Claude Code 终端恢复运行后，即使获批工具还在执行，桌宠也会清除等待审批提示。待回答的问题会继续显示。
- 修复子代理审批、父会话通知和工具调用的状态关联，SSH 会话也适用。
- 修复发布流程对已通过 CI 的识别。完整的 macOS 原生测试在 Apple Silicon 上运行，Intel 安装包仍独立构建、签名和校验。

## English

This release covers `v0.2.12` through `v0.2.14`.

- The desktop pet clears Claude Code's approval indicator when the terminal resumes, even while the approved tool is running. Unanswered questions stay visible.
- Claude Code subagent approvals and parent-session notifications are matched to the correct tool call, including in SSH sessions.
- The release workflow correctly recognizes successful branch CI. Full macOS native tests run on Apple Silicon, and the Intel installer is built, signed, and verified on its own runner.
