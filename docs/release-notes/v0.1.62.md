## Desktop appearance and layout

- Simplify Windows/Linux controls with smaller corners, flat fills, lighter borders and one keyboard focus ring. Make text menus opaque while retaining the existing dialog transparency.
- Group today's Token usage and API-equivalent cost into a compact, responsive summary with clearer numeric hierarchy. Improve section actions, collapsible settings, SSH form alignment, pet settings and panel menu visibility.
- Add independent Windows main-window and panel material choices in Settings → Appearance. Defaults remain Mica and Acrylic, with the current native fallback reported separately.
- Replace the full Agent tab list with common entries, a searchable picker and entry management. Removing an Agent pauses collection while preserving machine selections, sources, accounts and history for restoration.

## Native platform improvements

- macOS uses native sidebar navigation with a compact icon rail, retained pages and page-specific window titles. The menu bar uses one eye or phase-symbol position; pet labels remain readable at small scales, transparent pixels pass input through, and fullscreen hiding restores the pet without overriding a manual disable.
- Linux keeps its main window on native Wayland and uses an isolated X11 helper for the pet and panel, with bounded restart and a main-window fallback. Improve theme tracking, font caching, input shapes, drag snapping, window restoration and external browser launch isolation.
- Improve Windows titlebar, Snap Layouts, panel focus and recovery. Detect foreground fullscreen client bounds in addition to the shell notification state, and verify both fullscreen hiding and work-area restoration. Honor native 12/24-hour preferences independently of the interface language and expand localization checks.

## Data correctness and verification

- Correct native server memory totals when the monitor does not supply used memory.
- Exclude non-interactive Claude SDK, MCP and GitHub Action sessions after resolving source metadata, including legacy hook projections and descendants.
- Expand platform, browser, accessibility and packaging regressions. Release tags now run only the Release pipeline; release preparation and main synchronization avoid duplicate ordinary CI.
- Physical mixed-DPI/multi-monitor and full GNOME/KDE interaction acceptance remain separate from browser and virtual-desktop checks.
