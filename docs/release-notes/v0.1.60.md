## Cleaner desktop workspace

- Organize macOS, Windows and Linux into eight main destinations, with six preference categories inside Settings. Keep server monitoring separate from machine configuration.
- Replace repeated explanations with contextual help and expandable advanced controls. Simplify account setup, API connections, machine management, pricing, wakeups and onboarding while preserving quota-card detail, account switching and sampling.
- Add direct retry actions for failed quota reads and a useful account-selection action for empty panels. Preserve unsaved settings during language changes.

## Configurable session sounds

- Choose independently from six tones for input requests and task completion: Classic, Bell, Chime, Marimba, Droplet and Pulse.
- Adjust app sound volume from 0–100% and preview the current selection. System output volume remains unchanged; 0% mutes session sounds.
- Preserve the original tones and volume for existing configurations. Muted or disabled events are not replayed when sounds are restored.

## Automatic valuation and regression fixes

- Remove paused devices from active automatic-valuation coverage while retaining historical values and valid samples. Reconcile coverage when devices resume or directories change.
- Show paused rolling valuation accurately instead of treating an old active record as continuous updates.
- Expand regression coverage for navigation, retained drafts, notification settings, tone resources, volume and native window behavior. Correct the Windows/Linux CI expectation for paused Antigravity valuation.
