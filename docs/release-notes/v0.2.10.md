## Desktop overview, server filters, and usage charts

- Rename the overview’s Agent filter to **All** and the live session list to **Current sessions**. Show quota view labels alongside their icons when the main window has room.
- Show the visible and total host counts when a server filter is active. **Refresh** samples the enabled hosts in that filter. Windows and Linux also reduce repeated work when updating host status indicators.
- Open all dates from an empty usage view while keeping the other filters. Trend chart readings follow the visible models, and Windows and Linux reuse the daily totals during chart animation and date navigation.

## 中文

- 总览页的 Agent 筛选首项改为「全部」，会话列表改为「当前会话」。主窗口空间充足时，额度视图按钮同时显示图标和名称。
- 服务器页筛选后显示匹配数和总数。「刷新」仅采样当前筛选中已启用的主机。Windows 和 Linux 减少了服务器状态更新中的重复计算。
- 用量分析没有记录时，可保留其他筛选并查看所有日期。趋势图读数跟随可见模型，Windows 和 Linux 在播放动画和切换日期时复用逐日汇总。
