## 更新范围

本次更新覆盖 **v0.1.51 → v0.1.52**，修复账户分组布局、Antigravity 折叠额度显示和旧会话“待定”数量累积的问题。

## 账户总览

- 在约 1280px 的常见窗口宽度下，相邻的单账户 Agent 分组共享一行，Antigravity 和 DeepSeek 可以左右并排；单账户卡片填满各自分组，避免内部再次分列后缩成整行的四分之一。窄窗口仍按单列排列，保留 Agent 顺序和分组折叠。
- Antigravity 折叠卡片保留全部模型额度组，包括 Gemini 与 Claude/GPT。
- Swift 原生界面同步支持单账户分组并排。

## Antigravity 会话

- 本地与 SSH 优先使用步骤元数据中的生命周期时间判断活跃度，避免数据库文件被维护或同步后，让旧会话重新计入活动摘要。
- 缺少存活进程依据、状态仍无法确认的 AGY 会话在三分钟后退出活动摘要；明确等待输入的会话沿用已有生命周期规则。旧数据库格式缺少步骤时间时仍回退到文件时间，不将无法确认的状态冒充为已完成。

## 开发与验证

- 增加 macOS Tauri 2 的本地性能对比构建脚本和指定数据目录的启动脚本。正式 macOS 安装包继续使用 Swift 原生界面，本次不新增 macOS Tauri 发布附件。
- 补充 760–1800px 窗口下实际卡片宽度、AGY 展开卡片宽度，以及本地/SSH 会话时间处理的回归覆盖。
- 此版本不对 macOS 与 Windows 性能差异的原因作结论；本地对比方法见说明。
