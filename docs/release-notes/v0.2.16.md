## 中文

本次更新覆盖 `v0.2.15` 到 `v0.2.16`。

- **Kiro CLI 桌宠审批**。本机和 SSH 会话可从 Kiro V3 审批记录识别工具等待，并在处理后恢复会话状态。本机浮窗显示请求的工具和对象。Kiro CLI 3.4.0 及更新版本的新 V3 会话可单独启用浮窗审批，支持允许本次、拒绝本次和交回原终端。
- **Antigravity 计价与估值**。识别推理档位和模型版本的命名差异，并为可匹配的历史用量补齐价格。按模型组和额度窗口核验首次激活、跨采样请求与延迟到达的用量，修正重叠估值片段。
- **桌面界面细节**。调整导航、浮窗、表单与额度卡片的样式。侧栏滚动时提示尚未显示的条目，较大字号下价格列表按实际行高排列，空间不足时收起额度布局按钮的文字。

## English

This release covers `v0.2.15` through `v0.2.16`.

- **Kiro CLI approvals in the desktop pet**. Local and SSH session monitors now recognize pending Kiro V3 approvals and clear the waiting state when they are resolved. The local popover shows the tool and its target. New V3 sessions on Kiro CLI 3.4.0 or later can opt in to allowing once, denying once, or handing the request back to the terminal.
- **Antigravity pricing and valuation**. Match reasoning tiers and model-version spelling variants and backfill pricing for eligible history. Validate first activation, requests that cross sample boundaries, and late usage by model group and quota window, then correct overlapping valuation segments.
- **Desktop layout refinements**. Updated navigation, popovers, forms, and quota cards. Added sidebar scroll indicators, scaled virtualized price rows with text size, and hid quota layout labels when horizontal space is limited.
