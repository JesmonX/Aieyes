## Quota rings and account workflow improvements

Changes since v0.2.0:

- Add circular quota displays to account cards, with separate styles for the main window and floating panel. Short and long quota windows appear as two halves, while balances and single quota pools use dedicated displays.
- Show the first visible account's quota ring in the macOS menu bar and Windows/Linux tray, with configurable remaining-quota and reset-time labels.
- Improve account workflows and wakeup time selection, and require a confirmed Antigravity identity before closing authorization.
- Fix the macOS eye button so it fully collapses the sidebar.
