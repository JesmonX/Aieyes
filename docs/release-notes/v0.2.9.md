## More agents in Feishu chat channels

Changes since v0.2.8:

- Extend question hooks to local Qoder CLI and Qoder CN CLI, with single-choice and multiple-choice answers returned to the original question.
- Add local OpenCode background-service support for forms, one-time permission decisions, final replies and follow-up instructions in the same session. Recheck pending requests before submitting answers and keep uncertain submissions from being replayed.
- Read pending questions, approvals and final replies from Kiro CLI, DeepSeek Harness, Antigravity CLI and Qoder desktop records. DeepSeek Harness questions and approvals now correctly enter the waiting-for-input state.
- Discover both current and legacy Windows Kiro CLI login databases, including changes written to their WAL files.
- Update English translations and document the supported interfaces and verification limits.

Real Feishu delivery, Qoder hook loading, OpenCode permission and follow-up flows, and terminal input still require validation in the target environment.

## 中文

相对 v0.2.8 的更新：

- 本机 Qoder CLI、Qoder CN CLI 接入提问 hook，单选、多选答案返回原问题。
- 接入本机 OpenCode 后台服务：回答表单、处理单次权限请求、读取最终回复，并在同一会话续聊。提交前重新核对待处理请求，结果不明确时禁止重放。
- 读取 Kiro CLI、DeepSeek Harness、Antigravity CLI 和 Qoder 桌面版记录中的待回答问题、审批及最终回复；修复 DeepSeek Harness 提问和审批时的等待输入状态。
- Windows 同时发现新版和旧版 Kiro CLI 登录数据库，并检测 WAL 中的登录变更。
- 更新英文翻译，补充各 Agent 的接入能力与验收边界说明。

真实飞书投递、Qoder hook 加载、OpenCode 权限请求与续聊，以及终端输入仍需在目标环境验收。
