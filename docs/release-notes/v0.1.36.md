## 更新范围

本次更新覆盖上一公开版本 **v0.1.35 → v0.1.36** 的全部改动，包括桌宠显示与缩放、多会话状态、设置布局与性能、机器绑定、额度查询调度及历史日期范围。

## 桌宠动画、缩放与菜单

- 所有动作统一为每帧 100 毫秒（10 fps），保留当前状态持续循环和系统减少动态效果支持。
- 在「设置 → 常规 → 桌面显示」增加桌宠缩放，支持 50%–200%、每档 5%，可恢复 100%。比例按设备保存，重启或更换宠物后保留；图片、状态条、点击区域和窗口一起缩放，并限制在屏幕可见范围内。
- 图集先裁切为独立帧再缩放，避免相邻动作帧串色。Windows 修正透明度预乘处理、移除窗口阴影，将下方状态条改为抗锯齿圆角；Web 按显示器像素密度绘制透明 Canvas，macOS 同步调整缩放后的窗口几何。
- 多个会话共用一个桌宠，按状态优先级选择主动作，下方同时显示等待、工作、思考等状态数量。数量变化不会重启动画，长文字换行时窗口随之增高；修正失败与中断的动作映射。
- 修复 macOS 右键「打开面板」和「隐藏宠物」被禁用的问题。「打开面板」在面板已打开时保持打开，左键继续切换；隐藏偏好保存后可在设置中恢复。

## 估值、账户与模型映射

- 自动估值开关移到对应数据源小标题右侧。开启时确认采样条件，取消或保存失败保持原状态，关闭直接生效。
- Codex 说明改为「自动估值5h/7d限额和credits的价值」；其他 Agent 隐藏 credits 文案及控件。
- 整个「手动采样」区域默认折叠，包含开始入口、进行中任务和手动历史，标题显示进行中数量；自动采样历史独立保留。
- 「机器与目录」移到账户列表上方，每台机器收拢为一行。移除重复的账户介绍卡片、全局「刷新设备状态」按钮和每台机器的自动估值设置按钮；状态失败可按对应项目重试，登录与切换归入机器操作菜单。
- 已有模型映射默认折叠，可直接编辑、保存或取消；重名和并发修改冲突保留输入并提示。
- 「所选时间范围 · 待计价模型」简化为「待计价模型」。OpenRouter 列表默认显示五行，其余滚动查看，搜索仍覆盖全部模型。

## 机器绑定、采集与 Hook 接入

- 删除 SSH 主机后，关联目录保留原机器、目录、账户关系和历史，并进入「机器未绑定」状态；启用本机不会误读这些目录。新增显式重新绑定，校验重复目录、配置冲突及受管理 Codex home 身份，保留历史并重建采集基线。
- 本机与 SSH 均区分「资源监控」和「暂停整机采集」：前者控制资源指标，后者暂停历史、额度、会话和自动估值。旧配置迁移保留原有启停效果，后台结果提交前重新检查机器和目录资格。
- 机器行展示可点击的会话接入状态。Codex 使用日志，无需部署 Hook；Claude Code 和 AGY 提供自动接入、修复和停用入口，SSH 采集时自动部署观察 Hook，需要远端 Python 3。停用后不被轮询重新安装，日志回退仍保留，其他应用的 Hook 配置不受影响。

## 额度查询与采样协调

- 全局及账户额度查询间隔统一支持 5–86400 秒，账户留空继承全局。下次自动查询从上次完成开始计时，失败同样遵守间隔，恢复后不补跑积压查询。
- 共享数据目录的核心进程最多同时查询四个账户；同一账户和实际登录目录互斥，按到期顺序调度。快账户完成后立即发布结果，不等待其他慢账户。
- 定时、手动、原始 Codex 额度读取及估值采样共用查询协调；合并可复用的重复请求，采样边界仍要求满足时序的新快照。日志增量同步与额度保存按顺序完成，减少重复同步和重复估值推进。
- 历史与额度独立调度；配置变更、停用、休眠恢复及进程异常退出后重新检查任务资格并恢复协调状态。

## 历史范围与设置性能

- 保留今日、7/30/90/365 天，新增「所有」和「自定义日期」，自定义按本机时区包含首尾自然日。
- 新范围应用于总量、趋势、模型分布、每日明细和热力图；跨年热力图按年按需加载，长范围复用日聚合缓存，明细分页呈现。
- 隔离 macOS 的会话、桌宠及单账户状态通知，保留已访问价格页，减少切换时重复创建控件。
- Web 合并局部状态更新，跳过未变化内容；模型列表采用虚拟渲染，折叠内容展开时才创建。后台状态刷新保留输入草稿、焦点、选区和展开状态。
