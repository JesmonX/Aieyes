- 设置卡片采用面板式轻薄表面、细边框与圆角，侧栏融入窗口背景；透明材质成功时透出背景，不透明模式使用柔和浅灰与炭灰。
- 统一复选框尺寸、标签间距与首行对齐，改善开关、按钮、输入框的边缘及悬停、按下、焦点和禁用反馈。
