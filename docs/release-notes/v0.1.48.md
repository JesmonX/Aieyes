## 更新范围

本次更新覆盖 **v0.1.46 → v0.1.48**，集中减少界面重算、重复查询和后台读取，保留现有循环动画、用户配置的刷新间隔及完整采样历史。

## 界面与动画

- 菜单栏脉冲和桌宠动画改由原生动画机制驱动，沿用原有图片、颜色和逐帧时序；隐藏或开启减少动态效果时暂停。
- 菜单、桌宠和导航使用独立状态订阅，隐藏页面保留状态并暂停无关更新，恢复后显示最新数据。
- 热力图复用日期布局、最大值和标签，避免每次状态变化都重复解析全年数据。
- 原生菜单摘要独立刷新；页面按可见范围加载，相同范围与未变化数据复用快照，日期和时区变化会及时失效。

## 重复读取与后台调度

- 额度刷新合并发起窗口的返回结果和更新广播，避免同一次操作重复查询概览；其他窗口继续正常接收更新。
- 常驻摘要使用轻量采样投影，避免每次读取全部已完成历史；采样管理仍可连续查看完整记录，失败保留上次成功数据。
- 会话目录使用文件监听并保留周期校验，未变化的数据库及 WAL 复用解析结果；统一 Windows 路径标识，避免同一数据库被重复读取。
- 设备状态按实际连接上下文批量检查，只刷新失效或到期的状态；普通显示设置保存不再触发全面登录检查，显式刷新仍立即执行。
- 额度调度等待下一次到期或数据变化，空通知队列避免写事务；自动估值复用核心连接，禁用时退避等待。
- 删除唤醒任务时回收对应核心客户端，减少长期持有的后台进程。

## 稳定性与验证

- 拆分估值管理视图，修复 CI Swift 编译超时；保存失败提示使用独立错误状态，避免被后台刷新覆盖。
- 原生测试按 Metal 设备能力执行实时菜单动画验收，无 GPU 环境仍验证桌宠关键帧、窗口生命周期和缩放；新增 Intel macOS 日常 CI。
- 补充路径别名、DB/WAL 变化、缓存失效、重复广播、隐藏页面恢复、跨午夜与时区变化、账户身份及任务进程退出回归。
- 当前 Intel macOS 的隔离合成场景完成 40 分钟采样，优化后 UI CPU P95 为 3.28%；预热后约 30 分钟物理内存增长 11.12 MiB。该结果不等同于所有个人数据场景的实际收益。
