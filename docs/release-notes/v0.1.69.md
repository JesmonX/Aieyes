## Account cleanup and quota cards

Changes since v0.1.68:

- Keep archived accounts visible and stop rediscovering deleted identities. Exclude expired credentials from new accounts and perform a one-time cleanup of previously discovered stale accounts.
- Restore Codex valuation cards, render Qoder credit buckets and public account IDs, align Qoder CN usage analysis, remove duplicate Bank Reset timestamps, and add account context menu actions across desktop surfaces.
- Update Qoder and Qoder CN account identity verification to match the public account ID presentation, covering email precedence, status summaries and metadata round trips.
- Stabilize the Kiro session fixture readiness check in CI so interactive session filtering is verified reliably on Unix runners.
