## Desktop pet session interactions

- Open waiting sessions from the desktop pet to review permission requests and answer questions when the session supports it.
- Switch between waiting sessions in the popover and return to the original terminal when needed.
- Read commands, details, and option previews in compact, selectable code blocks. Long lines wrap, and longer blocks remain scrollable.

## 中文

- 从桌宠打开等待输入的会话。在会话支持时，可在弹窗查看权限申请并作出审批，也可回答问题。
- 在弹窗中切换等待中的会话，需要时可回到原终端继续处理。
- 命令、详情和选项预览采用紧凑的代码块，支持选中复制。长行自动换行，超高内容可继续滚动。
