## Smoother quota views and earlier history updates

Changes since v0.2.3:

- Pause hidden, minimized and occluded macOS valuation windows, release their content and history reader when closed, and construct calculation details when expanded.
- Save macOS scroll positions in an independent background store to avoid refreshing unrelated settings views. Preserve existing positions, coalesced saves, close/quit flushing and retries after a failed write.
- Batch quota-card height measurements, invalidate cached sizes when fonts or appearance change, and stop observing removed cards.
- Size quota groups to their account count so other groups can use the remaining columns. Preserve reading order and the panel's single-column layout.
- Import local history while remote collection runs. Refresh committed sources before the full batch finishes, preserve source order and failure feedback, and handle duplicate revision notifications on macOS and desktop.
- Add reproducible interaction and history-sync benchmarks, layout-growth checks, scroll persistence checks and committed-history regressions.

In isolated tests, 32-account Chromium refresh latency fell from 637 ms to 171 ms. After warm-up, native analysis-scroll CPU time fell from 702 ms to 307 ms, and the median longest event-loop pause fell from 205 ms to 15 ms while still saving positions. With a simulated two-second remote delay, 1,000 local records became readable in a median 53 ms instead of 2,215 ms; the full batch still took about 2.39 seconds. These are scripted fixture measurements, not physical-input latency or real provider response times.

## 中文

相较 v0.2.3：

- macOS 估值窗口在隐藏、最小化或被遮挡时暂停更新，关闭后释放内容与历史读取通道；展开时再构建计算依据。
- macOS 滚动位置改为独立后台保存，避免触发无关设置视图刷新；保留原有位置迁移、合并写入、关闭与退出保存，以及写入失败后的重试。
- 限额卡片批量测量高度，字体或外观变化时更新尺寸缓存，并及时停止观察已移除卡片。
- 限额分组按账户数占用列宽，其余列可继续排列其他分组；保留阅读顺序和面板单列布局。
- 本地历史导入与远端采集并行，已提交的来源可提前刷新；保留来源顺序、整批忙碌和失败反馈，处理 macOS 与桌面端重复修订通知的竞态。
- 增加可复现的交互与历史同步基准，以及布局增长、滚动保存和同步中提前刷新的回归检查。

隔离测试中，32 账户 Chromium 刷新延时从 637 ms 降至 171 ms。热身后的原生分析滚动 CPU 时间从 702 ms 降至 307 ms，最长事件循环停顿中位数从 205 ms 降至 15 ms，位置保存保持开启。模拟远端延迟 2 秒时，1,000 条本地记录首次可读中位数从 2,215 ms 降至 53 ms，整批仍约需 2.39 秒。以上为脚本回放与夹具测量，不代表物理输入延迟或真实服务商响应时间。
