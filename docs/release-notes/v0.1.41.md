## 更新范围

本次更新覆盖上一公开版本 **v0.1.40 → v0.1.41** 的全部改动，集中提升 Windows 主窗口、设置、控件、菜单、弹窗和悬浮面板的质感与动效。

## Windows 界面

- 为卡片、按钮、导航和弹出层增加轻玻璃高光、细边缘与分层阴影；菜单和弹窗保持清晰的文字底色，浅色、深色主题均适配。
- 沿用项目共享配色、鸿蒙黑体、字号、控件尺寸、布局与圆角规范。Linux 保留原生选择控件，macOS 原生界面与桌宠行为保持原有设计。
- Windows 单选下拉使用与页面一致的菜单，保留原生表单值、尺寸、禁用状态和校验。支持方向键、首尾跳转、文字搜索、确认与取消；动态选项、表单重置和程序回退会同步到可见控件。

## 动效与交互

- 增加按钮按压回弹、开关反馈、导航选中背景过渡、页面切换、侧栏展开、菜单和弹窗进退场，以及悬浮面板展开动效。
- 后台数据刷新不重复播放页面动画；打开下拉菜单时保留当前页面，关闭后再更新。快速切换会清理旧动画和菜单，Escape 先关闭当前下拉，焦点返回对应控件。
- 遵循减少动态效果、减少透明度和高对比度设置；不支持自绘菜单的环境自动使用原生控件。面板或页面隐藏时停止待执行的界面动画。

## 验证与预览

- 新增真实动画开启的浏览器交互回归，并接入桌面 CI，覆盖键盘与焦点、保存与回退、动态控件、后台刷新、快速开合和兼容回退。
- 提供浅深色主窗口与面板的可复现动效录制脚本，继续检查 Windows/Linux 布局、最小窗口、缩放与共享设计参数。
- 浏览器录制使用合成数据；真实 Windows 10/11 的桌面材质和混合 DPI 仍需交互桌面验收。
