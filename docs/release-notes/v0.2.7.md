## Feishu session control, accurate usage, and precise navigation

Changes since v0.2.6:

- Add optional Feishu personal chat control in Settings → Chat channels, with a long connection, system credential storage, and pairing to one account.
- Send session questions and final replies to the paired chat. Reply to a notification to answer or continue the original session, with local and SSH support based on the Agent's available controls. Reuse existing Codex interfaces and provide optional tmux and macOS terminal adapters.
- Keep instructions bound to the selected session and turn, require the specific notification for a one-time approval, and retain instructions when the target or permissions cannot be verified. Persist delivery and command states; submissions with uncertain outcomes are never replayed automatically.
- Correct parent and child Agent token attribution across sources, deduplicate native events, and capture final token writes after short or completed turns. Show input, output, cache details, usage timestamps, and distinct session IDs.
- Improve request timing for Pi, Oh My Pi, and Kimi. Show partial output speed with its token coverage when only part of a turn has reliable timing, and avoid counting a request's duration more than once.
- Improve navigation to existing Codex desktop threads and macOS terminal tabs or panes. Match IDE windows using full workspace paths, recheck process identity, and report the actual level of navigation available on each platform.
- Add the repository's Apache 2.0 license file.

Feishu control is off by default. Live Feishu delivery, native pending-request replay, and actual terminal input still need validation in the target environment. Terminal, desktop, and SSH support varies by Agent. See the [chat channel setup and support guide](https://github.com/JesmonX/Aieyes/blob/v0.2.7/docs/chat-channels.md).

## 中文

相较 v0.2.6：

- 在“设置 → 聊天渠道”增加可选的飞书个人私聊控制，使用长连接、系统凭据库和单账号配对。
- 向已配对私聊同步会话问题与最终回复；引用通知即可回答或继续原会话。本机和 SSH 按 Agent 的实际控制能力接入，复用既有 Codex 接口，并提供可选的 tmux 与 macOS 终端适配。
- 指令绑定具体会话和轮次，单次审批必须引用对应通知；无法核验目标或权限时保留指令。持久化收发与执行状态，结果不确定的提交不会自动重放。
- 修正跨来源的父、子 Agent Token 归属与原生事件去重，补收短轮次和完成后的末次 Token 写入；显示输入、输出、缓存分项、用量记录时间及可区分的会话编号。
- 改进 Pi、Oh My Pi、Kimi 的请求计时；只有部分可靠计时时显示“部分速度”及 Token 覆盖率，同一请求的耗时不重复累加。
- 改进既有 Codex 桌面会话、macOS 终端标签页与分屏的跳转；IDE 按完整工作目录匹配窗口，重新核验进程身份，并按各平台的实际定位结果反馈。
- 补充仓库的 Apache 2.0 许可证文件。

飞书控制默认关闭。真实飞书投递、原生接口未决问题重放与实际终端输入仍需在目标环境验收；终端、桌面和 SSH 支持范围取决于 Agent。详见[聊天渠道配置与支持说明](https://github.com/JesmonX/Aieyes/blob/v0.2.7/docs/chat-channels.md)。
