## 更新范围

本次更新覆盖上一公开版本 **v0.1.37 → v0.1.38** 的全部改动，重点改善三端设置交互、账户设备初始化、唤醒任务与桌宠导入体验。

## 三端界面与设置

- Windows/Linux 内容样式与 macOS 对齐，统一控件、卡片、面板、弹窗与图标；改善窄窗口、长路径、长日期范围的图表标签和菜单键盘操作。
- 常规设置支持连续编辑和排队保存；保存失败保留草稿，登录、切换及后台刷新保留期间的新编辑和模型映射。
- 账户卡片默认按 Agent 自动展示排序前五个账户；手动选择可不限数量或留空，并可恢复自动模式。
- 登录、切换、额度与估值统一考虑 Agent、机器采集和目录启用状态；条件空态可直接打开最近 365 天详情。

## 账户设备与唤醒任务

- 前置命令按账户与机器保存，同机目录共享，新关联目录继承；远程旧代理字段不再参与执行，本机代理继续保留。
- 配置升级至 v10。无冲突的旧命令自动迁移；同一账户设备存在不同历史命令时提示重新设置，迁移期间不连接远端或启动暂停任务。
- 已部署任务后台同步账户环境并保留启停状态；失败保留待同步标记，运行或启用前可重试。
- 唤醒列表与任务状态独立加载，各任务操作互不阻塞，旧请求不再覆盖新状态；已关联且身份匹配的离线或暂停目录可保存草稿。
- 修复 Codex 账户切换后复用旧额度基线的问题，避免将其他账户期间的共享用量计入当前账户估值。

## 桌宠导入、库与动画

- 支持本地 ZIP、pet.json、资源链接、已适配的 Codex Pet/Petdex/CodexPets 页面和命令，以及 npm 包写法；仅下载和解析素材，不执行安装命令或包脚本。
- 新增持久化桌宠库，展示名称、来源、作者与动画预览；导入后立即使用，保留旧桌宠，相同内容去重，同名不同内容可并存。
- 恢复 Aieyes 自身历史缓存中的有效桌宠，逐项报告损坏素材；导入失败或提交前取消保留原选择。
- 动画使用持续时间轴与统一逐帧时长，减少状态刷新引起的重启；库预览仅在可见时播放，并遵循减少动态效果设置。
- 桌宠菜单新增设置入口，macOS 支持工作区边缘吸附；中断状态使用 idle 动画并保留“已中断”文字。
