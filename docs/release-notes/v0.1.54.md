## 更新范围

本次更新覆盖 **v0.1.53 → v0.1.54**，加入简体中文与 English 切换，新增已有账户与原生连接扫描、智能价格引用，并改进桌面刷新、历史处理及官网展示。

## 中英文界面

- macOS 原生界面及 Windows/Linux 界面支持中文与 English，覆盖菜单、账户、额度、设置、桌宠、弹窗、通知和应用错误提示。可在外观设置或面板语言按钮中切换，偏好跨窗口、重启和升级保存。
- 语言切换保留打开的编辑器、未保存输入、筛选和选择项；修复跨窗口切换时旧设置可能把语言改回去的问题。账户名称、文件路径及用户输入保持原样，token、API、credits 等术语沿用原有写法。
- 日期、月份、数字和无障碍标签使用对应语言；修复英文余额前缀截取，保持紧凑面板和窄窗口可用。
- 三端共用离线词库，增加精确文案覆盖、参数完整性、双向切换、弹窗草稿、中文用户数据和窄屏布局回归。

## 账户发现与价格引用

- 可以按机器一键扫描已启用 Agent 的已有登录和原生 API 连接，也可在 Agent 账户页扫描已启用机器。支持本机和 SSH 目录，按可确认身份关联账户，保留已有手动名称与归档状态。
- 原生凭据继续保存在原客户端中，Aieyes 仅保存定位及非敏感元数据。扫描不执行登录、切换或模型请求；无法确认的连接显示待验证，可单条或批量取消引用。
- 模型价格增加「智能引用」，结合模型名称、版本、日期与供应商匹配已同步价格，生成可编辑映射；保留手动映射与已有冻结成本。
- 额度卡片只展示已计算的 credits、5h、7d 估值，部分缺失时不再堆叠占位符；有效零值和历史估值仍可查看。

## 历史、监控与交互

- 改进 Codex 分支会话的增量历史归并及 Qoder 状态读取，补充跨平台路径、完整重扫和重复导入回归。
- 服务器页支持按主机筛选，CPU 与内存摘要使用一致的紧凑布局。
- macOS 合并滚动位置写入，减少无变化数据、桌宠偏好和菜单状态造成的重复刷新；保留真实更新、忙碌反馈、展开状态与设置草稿。
- 修复 Intel macOS CI 的异步采样测试竞态：以进度到达和明确的确认信号协调测试，不再依赖固定的短暂停顿。

## 官网

- 更新中英文官网和 README，采用无边框布局、侧边栏功能切换及响应式排版。
- 总览、分析和服务器保留少量真实英文界面截图；账户、会话和定时任务改用文字与动效表达。展示一张展开的 Codex 卡片，并加入月薪喵逐帧动画。
- 支持键盘切换、图片放大与焦点恢复，动效遵循减少动态效果的系统偏好。

## English

Aieyes now supports English and Simplified Chinese across macOS, Windows and Linux. Switch languages from Appearance settings or the panel without losing open forms or drafts. This release also adds discovery of existing accounts and native connections, editable model price references, history and refresh improvements, and a redesigned bilingual website with real English screenshots and animated pets.
