## 更新范围

本次更新覆盖 **v0.1.50 → v0.1.51**，修复总览卡片布局和停用 Agent 的显示，统一 macOS 与 Windows 桌面菜单，改进 Antigravity 自动估值，并按创建来源筛选 Codex 活动会话。

## 总览与桌面菜单

- 额度摘要按窗口数量分列，充分使用卡片宽度；GPU、文件系统和网卡摘要采用平衡网格，四张显卡在宽度足够时显示为 2×2，窄窗口自动退列，避免缩窗时资源条溢出。
- 总览 Agent 选择器仅显示已启用的 Agent；停用当前选择后回到总览。历史分析仍可查询停用 Agent 的数据。
- macOS 与 Windows 按入口统一右键菜单，增加“检查更新”；菜单栏／托盘提供随状态变化的“隐藏桌宠／显示桌宠”，并保留唯一入口保护。

## 自动估值

- 修复 Antigravity 空闲模型组或窗口重置时间移动导致其他有效消耗被拒绝的问题，各组及窗口独立核验；真实重置、用量回退和不完整证据仍不会混入估值。
- 自动估值使用最近 90 天的有效区间滚动计算，权重每七天减半，同时考虑消耗量与成本；账户、套餐、模型组和额度窗口分别汇总，手动采样保留原有行为。
- 开启 Antigravity 自动估值后，后台分批恢复已有历史证据，可中断、恢复和重复执行；保留原始用量、旧估值及其价格依据。展示有效片段数量和等待原因。

## Codex 活动会话

- 仅将创建来源严格为 `cli` 或 `vscode` 的会话计入活动列表、数量、摘要及桌宠状态；排除 `exec`、子代理、未知或缺失来源。
- 不根据 `originator` 或工具名推断来源，正常会话调用 `exec_command` 不受影响；本地与 SSH 使用相同规则，保留大日志文件头及增量游标中的来源。
- Windows 使用卷与文件 ID 识别日志替换，防止同名文件沿用创建时间时继承旧来源。

## 验证

- 发布准备前，核心四平台、macOS 双架构原生回归、双架构桌宠图形以及 Windows/Linux 桌面 CI 全部通过。
- AGY 历史恢复在真实数据库的临时副本上验证，恢复出 10 个有效区间、19 个估值片段；原始用量、额度快照、设置及旧估值保持不变。实际恢复结果取决于本机已有证据完整性。
