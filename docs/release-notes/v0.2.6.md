## Sessions workspace, system integration, and clearer feedback

Changes since v0.2.5:

- Add a dedicated Sessions page with running, waiting, and recently ended sessions, agent filters, lifecycle metadata, and local terminal/IDE navigation.
- Consolidate panel account selection, account ordering, and background sampling into settings. Search settings, open the first result with Enter, and jump from a panel account to its highlighted overview card.
- Add 360/450 panel widths, clearer light-mode cards, shared empty states, animated quota rings and numbers, refresh feedback, and macOS haptics for sorting, snapping, and sliders. Restore the native sidebar's collapsed state reliably.
- Add launch-at-login controls, navigation-only `aieyes://` links, a macOS Dock waiting count, and a one-time update banner with bundled release notes.
- Add optional JSON, text, Bark, Slack, WeCom, and Feishu webhooks for quota resets, session events, and server alerts. Failed business acknowledgements retry even when the receiver returns HTTP 200.
- Add recent CPU, memory, and GPU trends and sustained server alerts. Sampling failures, pauses, and long gaps restart alert timing.
- Show progress and allow cancellation of cold usage aggregation while retaining the previous result. Reuse status responses across equivalent filters and avoid recalculating usage on quota-only updates.
- Keep model legend toggles bound to current selection, hide empty Kiro IDE drafts, and add an interactive website demo that defaults to Windows.

Cold aggregation can still take seconds on large histories. WidgetKit is not included. Windows/Linux login registration, real push services, and physical haptic feedback still need device-level verification.

## 中文

相较 v0.2.5：

- 新增独立会话页，显示进行中、等待输入及最近结束的会话，支持 Agent 筛选、生命周期信息与本机终端/IDE 跳转。
- 面板账户、账户顺序及后台采样收进设置；支持搜索设置、回车打开首项，以及从面板直达并高亮主窗口账户。
- 增加 360/450 面板宽度、浅色卡片层级、统一空态、额度环与数字过渡、刷新反馈，以及 macOS 排序、吸附和滑块触觉。修复侧栏收起状态恢复。
- 增加登录启动、仅用于导航的 `aieyes://` 链接、macOS Dock 等待数及更新后的本次更新入口。
- 可选 Webhook 支持 JSON、文本、Bark、Slack、企业微信和飞书，推送额度重置、会话及服务器事件；HTTP 200 的业务错误也会进入重试。
- 服务器卡片增加 CPU、内存和 GPU 近期走势及持续超阈值告警；断采、暂停和长间隔会重新计时。
- 冷用量聚合显示进度并可取消，保留上一结果；等价筛选共享状态响应，额度变化不再重算用量。
- 修复模型图例重复切换，隐藏空 Kiro IDE 草稿；官网新增交互演示并默认展示 Windows。

大量历史的冷聚合仍可能耗时数秒。未包含 WidgetKit；Windows/Linux 登录注册、真实推送服务和物理触觉仍需设备验收。
