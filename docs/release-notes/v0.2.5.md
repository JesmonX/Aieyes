## Session insights, wakeup timing, and clearer analysis

Changes since v0.2.4:

- Live session rows on macOS and the desktop app show the project directory, the elapsed time of the current turn, session and turn token totals, and output speed where request timing is recorded. Click a local session to bring its terminal or IDE window to the front.
- Session tokens join the live session to imported history by native session ID within that session's own source. Active local sessions are imported early on a separate connection while collection continues; a new `events_session` expression index keeps the lookup near 30 ms on an 800,000-record copy.
- The wakeup editor suggests a time from the last 30 complete natural days of the target machine: three hours before the median first use, rounded to the nearest quarter hour. Runs started by the Aieyes runner are excluded by native session identity rather than overlapping time, and no suggestion is made without time zone rules or run records.
- Analysis KPIs compare with the previous period of equal length and add a sparkline of the selected days. Priced cost is still compared when pricing is incomplete, and "no records last period" is distinguished from a real zero; the dashboard payload gains `comparison`.
- Server filters merge into one row, hosts without sampling use a single line, agent and server options fade at the clipped edge, and the GPU "utilization" label is no longer truncated.
- macOS account quota groups use the same waterfall layout as the web UI, each group taking only its own account columns; the web layout re-runs after heading heights change with fonts or language.
- Access and accounts settings gain a capability overview; the core contract adds `history` and `sessions` capabilities, and the session-monitored provider list now follows the contract.
- Copy fixes: no "—" without Bank Reset data, a shorter native-credits note, "N quota estimates collecting samples", and the footer now reads "Network: system proxy · N ms".
- Regenerate the website screenshots and update the sidebar patch to the current `NavigationSplitView` structure.

Session switching was confirmed on Ghostty and ChatGPT's built-in Codex only; token joins for Claude Code, Antigravity, DeepSeek Harness, Qoder and OpenCode have not been verified on real long sessions; the wakeup suggestion remote path was exercised against simulated hosts. See the full changelog in `docs/changes.md` for verification notes.

## 中文

相较 v0.2.4：

- macOS 与桌面端的会话行显示项目目录、本轮已用时间、本会话与本轮 Token，以及有可靠请求计时时的输出速度；点击本机会话可切换到所属终端或 IDE 窗口。
- 会话 Token 按原生会话 ID 关联已导入的历史，并限定在该会话自己的来源；活跃的本机会话在独立连接上提前导入，采集继续进行。新增 `events_session` 表达式索引，80 万条记录的副本上单次查询约 30 ms。
- 唤醒编辑器按目标机器最近 30 个完整自然日推荐时间：取首次使用中位数前 3 小时，按刻钟取整。Aieyes 运行器启动的运行按原生会话身份排除，而不是按时间重叠判断；缺少时区规则或运行记录时不推荐。
- 分析页 KPI 与上一个等长周期对比，并显示所选日期的小折线。计价不完整时仍比较已计价成本，区分“上一周期无记录”与真实为 0；`dashboard` 新增 `comparison`。
- 服务器筛选合并为一排，无采样主机单行显示，Agent 与服务器选项在被遮挡一侧渐隐，GPU“利用率”标签不再截断。
- macOS 账户额度分组与 Web 端采用相同的瀑布流布局，每组只占自己账户数的列；Web 端在字体或语言变化导致标题高度变化后重新排布。
- “接入与账户”新增接入能力一览；核心合约新增 `history`、`sessions` 能力，会话监测的 Provider 列表改由合约决定。
- 文案修正：没有 Bank Reset 数据时不再显示“—”；原生 Credits 说明更短；“N 项额度估值正在积累样本”；底栏改为“网络：系统代理 · 延迟 N ms”。
- 重新生成官网截图，`scripts/website/render.py` 的侧栏补丁更新为当前 `NavigationSplitView` 结构。

会话跳转仅在 Ghostty 与 ChatGPT 内置 Codex 上实机确认；Claude Code、Antigravity、DeepSeek Harness、Qoder、OpenCode 的会话 Token 关联尚未在真实长会话上端到端验证；唤醒推荐的 SSH 路径只在模拟主机上测试。完整核对说明见 `docs/changes.md`。
