- 折叠和展开时保留一份资源摘要，CPU、内存及每张已选 GPU 使用紧凑圆环显示占比。
- 每张 GPU 单独显示编号、型号、利用率、已用／总显存和显存占比；多卡自动换行，缺失数据明确显示“—”。

- 同步更新 macOS 原生界面、Windows/Linux 桌面界面和浮动面板。

- 窗口产生使用量后恢复真实倒计时；初次显示、定时刷新和原生界面采用相同规则。
- 调整仅影响展示，保留原始重置时间用于查询、采样和存储。

- GPU 利用率／显存改为紧凑进度条；服务器折叠摘要增加文件系统容量。额度估值使用单行 5h／7d，Credits 估值入口独立成行。
