## 更新范围

本次更新覆盖上一公开版本 **v0.1.41 → v0.1.42** 的全部改动，重新组织 macOS 原生应用与 Windows / Linux 桌面应用的导航、账户摘要、监测面板和设置。

## 主窗口与设置

- 统一侧栏按「监测、配置、偏好」分组，集中提供 Agent 总览、用量分析、服务器及各项设置。侧栏可收起，短窗口中可独立滚动。
- macOS 设置并入主窗口；菜单栏、桌宠、设置深链接与 `⌘,` 进入对应页面，`⌘1` / `⌘2` / `⌘3` 切换三个监测页面。
- 接入设置按 Agent 分为账户、API 连接、机器与目录、估值与采样四个分区，分别记住展开状态，深链接自动展开目标区域。页面切换保留阅读位置、设置草稿和原有保存流程。

## 面板与账户摘要

- Agent 面板按 **会话状态 → 今日用量 → 账户限额** 排列，底部操作固定，内容独立滚动；趋势、模型圆环和每日明细集中到用量分析页。
- 账户按 Agent 分组，新账户卡片默认收起，摘要保留身份、订阅、额度、重置时间和余额。展开后提供切换账户及「查看分析」，已有展开偏好和手动排序继续生效。
- Antigravity 保留全部模型组及各组额度、时间窗口和重置时间；分组标题显示账户数量及需留意数量，后台刷新同步更新提醒。
- 会话摘要突出等待输入和执行失败，展开后显示 Agent、机器、状态和真实更新时间。完全空闲时隐藏摘要，来源异常仍可见。
- 服务器用分类色块与细进度条呈现 CPU、内存、GPU、存储和网络；缺失读数、零值、采样时间及失败或暂停状态明确区分。

## 筛选与交互

- 面板、Agent 总览和用量分析分别保存筛选，普通页面切换互不影响；旧筛选偏好自动迁移，移除账户或来源后同步校正。
- 显式「查看分析」带入当前 Agent / 账户，清除分析页的来源和模型限制，并保留已选日期范围。菜单栏总量始终显示全部账户的今日汇总。
- 刷新保留账户展开状态、滚动位置和键盘焦点，避免不同筛选的数据混用。Web Token 细分弹层限制在可见内容区内，避免被底栏裁切。

## 视觉与验证

- 统一共享字号、间距、圆角和分类色，卡片采用半透明底、渐变、细边框与轻阴影；明暗主题下的单色 Agent 图标保持清晰对比。
- 适配减少透明度、增强对比度、强制颜色及减少动态效果设置。
- 新增工作区回归与可复现预览，覆盖筛选隔离、偏好迁移、上下文跳转、账户摘要、最小窗口、弹层边界和焦点保留；原生模型、浏览器及桌面 CI 检查通过。
