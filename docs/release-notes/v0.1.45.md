## 更新范围

本次更新覆盖上一公开版本 **v0.1.44 → v0.1.45** 的全部改动，新增可选的 Codex 精确计数，减少 fork 历史提示打扰，并统一桌面控件的柔和外观。

## Codex 用量计数

- 在“设置 → 常规 → 刷新与历史”新增“精确计数”，新安装和升级用户默认关闭。本机和 SSH 使用同一设置；关闭时按各会话自身累计量计数，允许 fork 继承的父历史重复计入，不再校验父历史。
- 开启后扣除可验证的父历史用量。父记录缺失或不完整时，暂不计首段不确定累计，后续有效增量继续统计；父历史恢复后自动补全。
- 切换模式后的下一次同步自动重读已有 Codex 日志，随后恢复增量读取。保留事件身份、来源关系、冻结价格和审计记录，支持反复切换及历史用量双向重算。
- 受影响的历史估值按原采样区间和价格生成替代记录；无法可靠重算的记录保留审计，避免将继承累计量误认作单次请求的订阅消耗。

## 同步提示

- fork 父历史问题仅在精确计数设置内查看，不再作为同步失败，也不在其他页面显示告警；旧版缓存提示同步适用。
- 普通刷新错误支持关闭本次提示。关闭不改变真实操作结果；下次同步仍失败时可以再次显示，不提供永久屏蔽。
- 同时出现父历史问题和普通读取错误时，普通错误仍正常显示，并保留按来源重试。

## 桌面控件与外观

- macOS、Windows/Linux 的按钮、输入框和选中状态统一采用柔和底色；主要操作使用淡强调色，危险操作保留语义色。
- 减弱 Windows 窗口亮边，协调菜单、弹窗与卡片透明度和模糊效果，避免服务器嵌套资源分组重复叠加卡片底色；原生材质失败、减少透明度和高对比度模式保留对应降级。
- macOS 共享控件样式保留原生编辑、焦点、Return／Escape 快捷键及禁用行为，并覆盖账户、SSH 导入、估值、唤醒和更新等界面。

## 回归验证

- 核心三平台、macOS 原生及 Windows/Linux 桌面 CI 已通过；新增默认计数、模式切换、旧游标升级、历史估值重算和提示关闭回归。
- 真实核心浏览器回归覆盖缺失父历史时的两种计数结果及设置内诊断；补充控件透明度、高对比度、焦点、输入和快捷键检查，并修正原生控件测试等待视图就绪的时序。
