## Desktop pets

- Pet animations restart only when the sprite, action row, frame count or effective frame timing changes. Switching sessions, starting a new turn or updating labels and counts no longer snaps the same action back to its first frame.
- macOS uses the correct discrete keyframe layout (N images, N+1 key times) and keeps loaded images tied to their action row, so changing actions restarts once.
- Settings → Desktop display adds a "Uniform animation (debug)" toggle, off by default and stored per device. When enabled every frame lasts 100 ms for the pet and library previews; Reduce Motion still takes priority. Standard timings and sprites are unchanged.

## Account cards and today's usage

- The quota update time moves to the card footer next to "View analysis" and takes no space when empty. The macOS account switch row is vertically centered and wraps when narrow.
- The account switch button, subscription badge and Bank Reset use neutral colors; remaining percentage, balances, estimates, quota bars and warnings keep their colors. Windows/Linux Bank Reset gains the stack icon and follows the macOS order after credits.
- The missing-price warning shares the action area with "View analysis", so showing or hiding it no longer changes the card height.

## Quota refresh after clock changes

- Quota snapshots carry a backward-compatible per-account `observationRevision` assigned by the core when saving. Clients merge results by revision; `updatedAt` still represents data time.
- After the system clock moves backwards, a validated live query may replace a cached snapshot from the "future" and clears stale errors such as a previous lock conflict. Ordinary older samples and duplicate deliveries are still rejected without advancing the revision.
- The "account operation in progress" message is used only for real lock contention; permission and other file errors show their actual cause.

## Agent settings

- All joined Agents appear at the top in the user's order and wrap in narrow windows. "More Agents" searches every supported Agent, grouped as joined / not joined; choosing an unjoined Agent adds and opens it.
- Manage Agents supports drag and move up/down ordering with immediate saving (disabled while searching). `agents.manage` accepts `{order}` as an alternative to `{provider, visible}`; unknown, duplicate or unjoined IDs are rejected and collection settings are untouched.
- On Windows the integration page keeps the Agent header card and combines accounts, API, machines and estimates into one card with consistent padding, fixing content touching or overflowing the left edge. The collapsed sidebar no longer hides Agent entry labels.
