## Free account quota cards and session status

Changes since v0.1.71:

- Add Settings → General → Advanced with "Hide quota cards of free accounts" (off by default) on the desktop app and macOS. When a provider reports a free plan, that account's quota card is hidden in the main window, the panel, panel account selection and the menu bar quota. The account is still queried, and its card returns after an upgrade. Unknown plans, trials of paid plans and failed reads stay visible.
- Recognise free plans more reliably: Copilot Free accounts whose plan field now reads "individual", Gemini CLI and Antigravity free tiers under any display name, and WorkBuddy / CodeBuddy plans only when the service states the tier.
- Fix session status after pressing Esc in Claude Code, after local slash commands such as `/model` or `/clear`, and when a session has ended while its transcript still looked active. Qoder desktop sessions now show completed, failed, interrupted and waiting-for-approval turns correctly.
- Show a hint to run `qodercli status` when the saved Qoder CLI login has expired, instead of a generic initialization error.
- Fix Antigravity quota queries that returned no plan or a 403 "no valid license" because the client was not identified, and stop reporting a false account mismatch when a refreshed keychain login and an older file copy of the same login coexist.
- On macOS, a single quota card in the last row keeps the width of the cards above it, and an invalid request value is reported as an error instead of stopping the app.

## 中文

相较 v0.1.71：

- 桌面端与 macOS 新增「设置 → 常规 → 高级 → 隐藏免费账户的额度卡片」（默认关闭）。服务商返回免费套餐时，主窗口、面板、面板账户选择和菜单栏额度都不再显示该账户的额度卡片；账户仍按原间隔查询，升级为付费后自动恢复显示。套餐未知、付费套餐试用及读取失败的账户照常显示。
- 更准确地识别免费套餐：套餐字段已改为 "individual" 的 Copilot Free 账户、任意展示名称的 Gemini CLI 与 Antigravity 免费层级；WorkBuddy / CodeBuddy 仅在服务端明确给出层级时显示套餐。
- 修复 Claude Code 中按 Esc 中断、执行 `/model`、`/clear` 等本地斜杠命令后，以及会话已结束但记录仍显示活跃时的会话状态；Qoder 桌面端会话正确显示完成、失败、中断和等待批准。
- Qoder CLI 保存的登录过期时，提示在终端运行 `qodercli status` 刷新登录，不再显示笼统的初始化失败。
- 修复 Antigravity 因未标明客户端而读不到套餐、或返回 403 “no valid license” 的额度查询；系统钥匙串中已刷新的登录与同一登录的旧文件副本并存时，不再误报账户不一致。
- macOS 最后一行只有一张额度卡片时保持与上方卡片相同的宽度；无效的请求参数改为报错提示，不再导致应用中止。
