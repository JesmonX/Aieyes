## Agents 与多账户

- 新增 Agents 设置，按 Agent 选择机器与记录目录，配置立即保存，保存失败时保留输入并支持重试。
- 支持同一 Agent 的多个账户、账户归档与恢复，以及 Codex 登录、已有登录接入和独立限额刷新。
- 修正限额重置时间展示，使用接口返回时间，不再为满额窗口推算新周期。

- 修复模型映射添加与移除仅修改旧草稿、无法正确持久保存的问题。

## Windows 外观

- 内置鸿蒙黑体及完整许可，统一窗口、导航、控件、图表和悬浮胶囊的字体与尺寸。
- 主窗口与悬浮面板独立使用系统桌面材质，随主题及系统透明度设置更新；不可用时恢复不透明背景。
- 调整默认窗口尺寸、圆角与面板布局，并补充字体、透明度和多种缩放比例的检查。
