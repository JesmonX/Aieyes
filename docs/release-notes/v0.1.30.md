## 账户设备与切换

- “切换为此账号”按钮右侧显示“已登录设备 x/y”和“使用中设备 x/y”，账户设置使用同一统计口径；同一设备的多个目录只计一次，离线或未知状态提示待确认。
- 保留切换前退出 Codex / ChatGPT 的方式。Windows 应用请求正常退出，已确认的 CLI 和辅助进程可以自动关闭；经系统服务登记、进程 ID 和程序路径共同核实的 Codex 沙箱服务保留，不再阻止切换。
- 独立 API 实例及其辅助进程保留；权限不足、身份不明或应用拒绝退出时，保留原账户并提示处理。
- 改进多设备登录关联、逐台检查反馈，以及切换账号后唤醒目标和能力列表的同步。

## 外观与历史记录

- 新增经典、Tableau、Paul Tol、ColorBrewer Set2、Nord 五套图表配色，各支持明暗主题和高低对比度，主窗口与悬浮面板同步。
- 默认隐藏已删除账户的筛选项，历史用量仍保留；开启显示后只列出有历史记录的已删除账户。
- 改进并行导入的事务与锁竞争处理，失败保留已提交游标，完整重扫保持去重及历史价格一致。

## 稳定性

- 修复界面启动加载顺序、无 Codex 账户时的多余状态检查，以及 Windows 配色文件读取和测试夹具权限问题。
- 改进更新前对采样、写操作和授权任务的协调，取消或失败后恢复刷新。
