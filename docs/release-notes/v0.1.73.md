## Antigravity quotas and macOS navigation

Changes since v0.1.72:

- Read Antigravity CLI model-group quotas through agy's built-in `/usage`, restoring groups such as Gemini and Argon that could be missing from direct API results. agy can renew its own expired access token during quota and identity checks; account ownership is checked again before accepting the result. Custom agy paths work locally and over SSH, and IDE-only installations retain the API query path.
- Prefer the newer valid login when multiple saved credentials belong to the same Antigravity account. Show specific errors for expired logins, access restrictions, rate limits, timeouts, connection failures and CLI problems. Model-group quotas remain available when the separate AI Credits query fails.
- Add a macOS toolbar button to restore the sidebar after it has been fully hidden.
- Pack macOS quota cards into the shortest column, reducing empty space beneath shorter cards. The layout adapts when cards expand or the window resizes; multi-account groups keep a full-width section with their own card grid.
- Build both macOS architectures with Xcode 26.3 and the macOS 26 SDK so release and branch CI use the same native UI toolchain. The minimum supported macOS version remains 14.0.

## 中文

相较 v0.1.72：

- Antigravity CLI 改用 agy 内置的 `/usage` 读取模型组额度，恢复直接调用 API 时可能缺失的 Gemini、Argon 等分组。额度与身份检查中，agy 可自行续期已过期的访问令牌；接受结果前再次核对账户归属。本机和 SSH 均支持自定义 agy 路径，仅安装 IDE 时继续通过 API 查询。
- 同一 Antigravity 账户存在多份保存的凭据时，优先使用较新且有效的登录。登录过期、访问受限、查询过频、超时、连接失败及 CLI 异常分别显示具体原因；单独的 AI Credits 查询失败时，仍保留有效的模型组额度。
- macOS 工具栏新增侧栏切换按钮，导航栏完全隐藏后也能重新展开。
- macOS 额度卡片按最短列排列，减少较矮卡片下方的空白；展开卡片或调整窗口大小时自动重排。多账户分组保持整行展示，内部卡片独立排列。
- macOS 双架构发布与分支 CI 统一使用 Xcode 26.3 和 macOS 26 SDK 构建，保持原生界面工具链一致；最低支持系统仍为 macOS 14.0。
