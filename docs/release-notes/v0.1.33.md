## 自动估值入口与订阅采样

- 数据源页面每台机器旁直接显示自动估值状态和“自动估值设置”按钮，无需进入目录设置；macOS、Windows 和 Linux 同步调整。
- 数据源页面与额度估值页面共用设置。开启前须确认只使用订阅账户及其 credits，不混用 API／中转，并纳入影响额度的所有设备用量。
- 自动积累 5h / 7d 额度与 credits 的可信样本，遇到重置、混合消耗、缺失价格或身份不确定时等待，保留最后有效结果。
- 自动跟随共享 Codex home 的实际登录账户，切换后封存旧结果并重建基线，保留共享历史和已有手动采样。
- 修复 Windows 读取共享登录后无法开始手动采样的问题，并整合跨平台配置保存、来源可用性、唤醒调度与进程识别修复。
