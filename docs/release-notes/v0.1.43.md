## 更新范围

本次更新覆盖上一公开版本 **v0.1.42 → v0.1.43** 的全部改动，新增配置指南与 SSH 主机导入，并改善跨平台表单、账户执行环境和 Codex 历史识别。

## 配置指南与 SSH

- macOS、Windows 和 Linux 新增按目标组织的配置指南，涵盖用量与限额、网络代理、刷新间隔、服务器、定时唤醒、面板账户、计价和通知，支持跳转至对应设置。
- 指南结合账户、机器和查询状态显示检查结果，区分已配置、待验证及读取失败；服务器账户可直接进入对应设备的前置命令设置。
- 支持预览并选择导入本机 SSH config 中的主机别名，显示地址、用户及端口。连接继续沿用原 SSH 配置，预览不执行 Match 条件或 ProxyCommand。

## 界面与交互

- 调整表单控件宽度，短数值、名称、选项及长路径按内容和窗口宽度布局；改善窄窗口中的原生设置表单。
- 改善滚动条显示和固定占位，减少滚动时内容宽度变化；完善 Agent 分类色和图标展示。
- Windows 桌宠状态标签的背景随文字宽度调整，在不同 DPI 下保持居中。

## 修复与验证

- Codex 账户检查、限额、模型列表及切换操作使用配置的前置命令和执行环境；修正 Windows CLI 启动器对规范化路径的兼容处理。
- 本机及远端 Codex 分支历史按会话元数据识别父会话，避免导入或复制日志附带额外 UUID 文件名时识别错误。
- 更新滚动条、自适应选择框及 Windows 长短路径回归检查，增加 CLI 启动阶段诊断；发布前的核心、macOS 和 Windows / Linux 桌面 CI 已通过。
