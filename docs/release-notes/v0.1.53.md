## 更新范围

本次更新覆盖 **v0.1.52 → v0.1.53**，新增 Linux 原生桌宠、托盘和 Fedora RPM，补齐 Qoder 多机器身份、环境配置与历史状态支持，并改进 Codex 多账户估值、登录检查和历史分析。

## Qoder 账户与目录

- 本机和 SSH 机器的 Qoder 目录支持读取当前登录身份。“机器与目录”显示账户标识，并提供“刷新账户状态”；同一账户在不同机器显示相同标识，账户设备页标明是否与已绑定账户一致。
- 从 CLI 的当前账户响应识别身份，不依赖历史日志或 Credits 数值。账户切换后不会覆盖原账户绑定，查询失败保留带提示的上次结果；同一配置目录和执行环境在一次批量检查中共用一次查询。
- macOS、Windows 和 Linux 的目录列表与计数排除额度专用来源，修复本机多出空白目录的问题。额度连接仍可在账户设置中管理。
- 支持本机与 SSH 机器的 Qoder 环境配置及历史状态恢复；兼容不同 CLI 版本的状态密钥布局，补齐未完整写入会话日志的历史用量。
- 修复配置读取失败可能覆盖原文件的问题，改用保留文件权限的原子替换；状态收集在来源暂停或重绑定后停止写入，重复扫描不再无故刷新用量缓存，单个损坏状态文件不影响其他会话。

## Linux 桌面与安装包

- 新增原生透明桌宠和 StatusNotifier 托盘；托盘通过 D-Bus 工作，移除 AppIndicator 运行依赖，支持从托盘、桌宠打开面板及外部点击、Esc 关闭。
- Wayland 环境在可连接 XWayland 时自动选择兼容后端，并保留显式 GDK_BACKEND 设置；改进面板关闭按钮、窗口边框和导航居中，避免窄面板中“服务器”换行。
- 新增 Fedora RPM 安装包及对应更新签名，继续提供 DEB、AppImage；打包检查覆盖体积、符号剥离和 AppIndicator 依赖回归。
- 修复 Windows Qoder 环境模块编译，并按平台配置原生托盘特性，保持 Windows/macOS 托盘与 Linux D-Bus 实现兼容。

## Codex 估值与登录

- 共享目录的估值结合会话创建者、登录身份观测、切换边界和请求额度信息核验归属。恢复旧会话按有证据覆盖的使用区间判断账户，跨切换、身份冲突和观测缺口的片段不参与估值。
- 应用内切换账户前尝试补齐旧账户的采样尾段，新账户重新建立基线。旧自动样本保留，但未确认归属的金额退出当前汇总；估值不改变历史 Token 总量，也不等同于账户账单。
- 分开检查当前登录、账户档案关联和 CLI 可调用性，在运行位置显示待关联或程序不可用的原因，并提供完成关联入口。

## 历史分析与验证

- 历史用量统一按 Agent 展示，移除账户 Token 筛选并清理旧偏好；保留日期、来源和模型筛选，账户额度继续分别展示。
- 更新相关界面回归，并补充 Qoder 账户切换、目录路径、批量查询复用、失败结果保留和跨平台身份展示的验证。
- 完成 Fedora 真实 Qoder 历史读取、重复扫描、原生桌宠/托盘交互和 DEB/RPM/AppImage 构建检查；补充 Linux 窄面板导航与无 AppIndicator 环境回归。
