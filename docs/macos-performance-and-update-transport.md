# macOS 价格页、更新传输与面板重绘

延续 session `01a11958-9268-7b23-92a1-14a45d908a8c` 的三项优化计划，2026-10-08 实施。

## 价格页

价格列表由分组 Form 改为 ScrollView + LazyVStack，行按需创建。独立的 PriceCatalog 保存价格和过滤结果；相同快照不重复发布，行使用值比较避免无关状态刷新重新构建。首次进入价格页才读取，重新进入复用缓存，保存与同步后强制刷新。

价格读取拥有独立 EngineClient，不排队等待扫描或远程限额请求。读写重叠时通过 revision 丢弃过期结果并重新读取；失败保留旧数据并提供重试入口。保存成功但随后读取失败会明确提示，不把刷新失败显示为完整成功。

## 更新传输

AppUpdater 在发起 Sparkle 检查前启动独立的 `aieyes-core --update-transport` 子进程。子进程从已保存的设置读取代理，复用 network::client_builder 的 system/direct/custom 处理。每次检查、开始下载安装包时重新读取设置；同一传输周期使用固定配置。

传输桥只监听随机的 IPv4 回环端口，路径带每周期随机凭证。清单与包地址仍须为 HTTPS，重定向也受 HTTPS 限制。清单原始字节不改写，安装包流式转发并保留文件扩展名。没有中间落盘缓存；Sparkle 继续检查签名、解包和安装。外部 release notes 不另外发起不遵循应用代理的请求，现有内嵌更新说明继续显示。

- 检查总时限 25 秒，含传输桥启动；启动单独限时 5 秒。
- 清单每次请求限时 9 秒，仅瞬时连接错误、超时、5xx 或不完整清单最多重试一次。4xx 不重试。
- 安装包每次请求限时 10 分钟；响应尚未开始时允许一次有限重试，已经流式传输的内容不拼接重试。
- 用户可以取消检查或下载；关闭子进程 stdin 或终止子进程可中断卡住的上游请求。
- 记录阶段、代理模式、尝试次数和耗时，不记录代理凭据、完整 URL 或回环凭证。
- 下载进度独立 ObservableObject，仅进度视图订阅，不再刷新整个 RootView。

应用内代理选择改变后需要先保存应用配置。清单验签、包验签与安装授权要求未改变。

## 面板重绘

原问题的具体系统合成层根因仍未确认。此次改动针对已观察到的悬停/透明材质关联：生产 NSPopover 使用 PanelContainer，将全尺寸的 12% 底色移入独立原生 PanelTintView，动态 SwiftUI 内容叠在其上。底色只随外观/辅助功能变化更新；系统 NSPopover 继续提供唯一的模糊材质。减少透明度及增强对比度继续使用不透明底色。

菜单栏更新合并到下一个主循环，仅在实际变化时写入长度、frame、tooltip 和可访问标签；滚动样式配置同样去重。面板/详情不可见时移除周期 Timeline 并停止会话脉冲动画。DailyUsage 的复杂行拆成独立函数，避免原生优化编译时的类型检查超时，显示与复制语义不变。

## 验证

- `cargo test -p aieyes-core`：76 项通过；包含传输路径校验、瞬时失败重试、4xx 不重试、原始签名字节保留、无长度包的分块传输、包截断失败。
- `sh scripts/test-native.sh`：原生状态、价格缓存/强制刷新竞争、失败恢复、搜索、独立价格读取、窗口可见性、Sparkle 回调导出、取消及进度隔离。
- `python3 scripts/test-update-transport.py`：真实子进程配合记录型 HTTP CONNECT 代理，验证清单/安装包代理路由、直连覆盖、配置快照、非法凭证/协议拒绝，以及联网阻塞时取消。
- `sh scripts/test-native-performance.sh`：466/1,000 条价格的切换计时，以及每块屏幕浅深色真实 NSPopover。图像和 JSON 写入 `.local/performance-2026-10-08/`。合成鼠标事件加后台内容变更验证底色更新范围，不等同于物理鼠标悬停验收。
- `scripts/verify-update-transfer.swift`：可选真实网络测试，只读取清单和下载包，不调用安装器。通过 UpdateTransport 和 URLSession 下载，验证发布 Ed25519 签名，并确认篡改样本被拒绝。

原生 debug 构建最终验证：466 条模型三次切换 260/151/138 毫秒，1,000 条 163/154/127 毫秒，均低于 300 毫秒（含等待首帧调度及布局/显示，合成价格数据）。主 IPC 被人为阻塞 1.5 秒时，独立价格读取仍低于 300 毫秒。两块屏幕的浅/深色 NSPopover 均在合成悬停及后台内容变更中保持底色更新次数为 0；减少透明度关闭。当前环境未授予屏幕捕获访问，保存的是原生内容层图像，不含 WindowServer 最终桌面合成。

真实网络单次实测：使用当前保存的 custom 代理，清单 1.57 秒，8,271,970 字节安装包 1.84 秒；包签名通过，篡改样本拒绝。不是长期延迟承诺，也没有执行实际应用安装。

竖线修复验收仍需要在透明效果开启、物理鼠标进入/移动/悬停与后台刷新时持续观察。仅底色隔离测试和截图不能证明间歇性竖线彻底消失。


交付测试包：`dist/Aieyes.app`（debug、独立开发数据目录）。完整打包与嵌套代码签名检查通过；打包后程序使用合成数据实际启动并生成 65 张界面图，浅深色内容透明度和辅助功能不透明回退检查通过。没有替换 `/Applications/Aieyes.app`，没有发布版本。
