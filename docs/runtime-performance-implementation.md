# A+B 运行时性能优化实现与验收（2026-10-17）

基线提交：`ee0fdf4`（0.1.46）。本轮只修改工作区并生成 `dist/Aieyes.app` 开发版，不替换 `/Applications/Aieyes.app`，不发布。

## 覆盖范围

| 原计划 | 实现 |
| --- | --- |
| A1 / B 界面重算 | 导航、菜单与桌宠使用独立状态订阅；保留页面实例，隐藏页面暂停模型通知，恢复时读取最新状态。热力图缓存起始星期、最大值及标签，相同 days/cost 不重算。 |
| A2 / B 可见范围查询 | 原生菜单摘要独立连接，只查询可见 panel/overview/analysis；Web 延迟隐藏窗口读取；同范围请求合并，修订未变时复用有界快照，保留过期请求丢弃。日期及时区也参与失效，避免跨午夜复用昨日结果。 |
| A3 / B 历史数据 | `estimateHistory: "display"` 返回进行中、待确认及原卡片所需的最新/历史回退记录，省略冻结价格和分段明细。默认 `full` 保持兼容；管理窗口通过现有 list 接口独立读取完整历史。 |
| A4 / B 重复广播 | 操作 ID、修订事件及回退轮询协同；发起窗口合并 RPC 返回与广播，其他窗口正常更新；相同修订不重复查询。 |
| A5 / B 会话读取 | 本地目录监听后台注册/回收，避免 FSEvents 初始化阻塞会话通道；健康监听周期校验 60 秒，不支持/失败时保留 5 秒扫描。DB/WAL 指纹复用未变化结果，同轮 PID 检查合并；保留每秒状态刷新与原老化规则。远程数据库通过可选能力与游标指纹跳过重复 SQL，完整成功轮次淘汰旧游标。读取失败保留上次成功活动并标记异常。 |
| A6 / B 设备状态 | 新增批量接口，最多 3 个上下文并发；相同路径、连接与编译后前置命令等上下文共用来源快照，再投影账户。保留身份、配置指纹、认证修订及跨进程锁校验。 |
| A7 / B 生命周期 | 自动估值后台复用 Engine，失败重建；禁用时 60 秒退避，启用仍为 5 秒，配置变化可提前唤醒。移除任务后回收对应 EngineClient。连接内缓存设置，事务内重新校验。 |
| B 动画 | 菜单使用 AppKit 的同款系统 pulse，保留 22×22 图标、颜色和无障碍标签；桌宠使用离散 Core Animation 关键帧，沿用原图片、行帧数及每帧时长。身份未变不重启动画，隐藏/减少动态效果/更新期间停止。主窗口关闭不停止仍可见的菜单和桌宠。 |
| B 调度与通知 | 额度调度缓存修订和 nextWake，未到期不扫描全部账户；提交信号唤醒并保留 5 秒只读跨进程校验。空通知队列不创建写事务；桌面状态只在语义变化时广播，交互仍立即广播。 |

额度、历史和服务器的用户刷新间隔保持不变。外部设备状态检查按 `max(300 秒, 账户额度间隔)` 到期执行；登录、切换和显式刷新立即执行。普通显示设置、模型映射不触发外部设备检查；配置变化只重查指纹失效的上下文。

开发版已通过深度严格签名检查、可执行权限检查和空数据目录中的嵌入核心 hello；版本 0.1.46，原生程序与核心均为 x86_64。

配置格式和已有 RPC 名称保持不变。新增 `runtime.revisions`、`accounts.status.refreshBatch`、hello 能力标志及兼容的 tick.enabled；核心契约和两端生成资源已同步，共 109 个方法。内部使用 KV 修订、触发器及查询索引，不迁移业务表结构。没有合并核心进程、改写 SQLite 日缓存或增加用户性能开关。

## 缓存及失效

- 设置缓存以连接 data_version/自身写入变化校验；事务内重新读取，回滚不会污染后续缓存。
- 采样投影按 estimates 修订缓存，最多保留约 4 MiB；不缓存未提交数据。首次扫描使用类型与被替换 ID 的完整索引，避免相关子查询退化。
- 原生/Web 范围快照最多 4 份、每份约 2 MiB；数据修订、查询条件、日期或时区变化失效。
- 热力图布局约 4 MiB / 12 项；桌宠图集约 48 MiB / 8 项，按资源身份缓存，后台读取与裁剪。
- 失败保留上次成功显示；完整历史按需读取。未增加静态图标或降低现有动画帧时序。

## 实测

以下均为当前 Intel macOS、隔离合成数据、debug 构建，不可直接替代已安装版本的个人数据现场指标。CPU 为约 10 秒采样区间的进程 CPU 时间比例。

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 菜单 pulse + 桌宠循环，保留隐藏的 365 天主窗口，每秒更新服务器状态 | UI CPU 中位 55.09%，P95 58.80%（3 分钟对照，30 秒预热） | 中位 2.95%，P95 3.28%（40 分钟，10 分钟预热后 175 个样本） |
| 优化版稳定性阶段物理内存 | — | 起始 96.64 MiB，末尾 107.76 MiB，峰值 107.96 MiB；约 30 分钟增加 11.12 MiB |
| 1,000 条已完成采样摘要 | 首次 451.8 ms，热中位 403.8 ms，1.29 MB | 首次 50.9 ms，热中位 2.74 ms，1.63 KB |
| 10,000 条已完成采样摘要 | 首次 4,153 ms，热中位 4,032 ms，12.89 MB | 首次 440 ms，热中位 3.12 ms，1.63 KB |
| 10,000 个旧文件 + 80 个会话数据库，未变化轮次 | 中位 39.6 ms | 中位 8.2 ms；会话数均为 81 |
| 原生价格页热切换 | 本轮未重复该项对照 | 两轮 466 / 1,000 个模型 P95 分别为 49.1–85.8 / 63.2–77.8 ms，包含测试内固定等待 |

动画验收包含九个状态的关键帧、线性全局时间、逐帧时长、频繁状态更新不重启动画、减少动态效果及隐藏暂停；真实可见窗口的演示层采样观察到 7 个不同图片帧，确认持续播放。五种缩放 × 九种状态 × 深浅背景共 90 张静态截图，平均绝对 RGB 差异为 0.280 / 255，主要为渲染边缘差异。

合成场景满足探索性的 CPU P95 <10%、物理内存 <700 MB、稳定阶段增长 <50 MB 目标。没有据此宣称已排除所有泄漏，也未单独统计 NSConcreteData 对象数量。原先安装应用约 1.5 GiB 的现场基线与本次小型合成场景不同，不能直接相减作为实际用户内存收益。

## 回归与边界

- 核心完整测试、生产 Clippy、Tauri 测试、完整 Web UI、Swift 原生测试、原生视图性能及契约生成检查通过；core 子进程夹具按现有方式忽略。
- 新回归覆盖事务/回滚、外部写入失效、空通知与并发写者、截止时间/时钟回退、DB/WAL/替换/失败恢复、监听溢出及回退、批量身份/到期间隔/差异配置、重复额度广播、隐藏页面恢复及任务进程退出。
- Web 与 Swift 各 8 个完整历史/轻量投影展示对照通过，涵盖 Codex Plus/Pro、Antigravity 分组、credits、修正记录、进行中和待确认记录。
- 合成输入焦点、选择范围、滚动/展开及独立 IPC 响应回归通过；真实键盘/鼠标输入延迟未单独测量。真实 SSH、个人数据长期运行与系统通知投递仍需现场验收。

- 未安装、未推送、未发布。本轮保留现有核心 lane 隔离。
