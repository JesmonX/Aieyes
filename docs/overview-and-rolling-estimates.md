# 总览布局、菜单与滚动估值

## 总览与菜单

额度摘要按实际窗口数量分列，最多两列；窄卡片退回单列。账户卡片列数也不超过账户数量。GPU、文件系统、网卡摘要使用数量感知的平衡网格：同样行数下减少空列，四项在宽度足够时排成 2×2；无法消除的单项末行使用整行宽度。详细设备列表继续使用原有虚拟化。

Agent 总览只显示启用的 Agent，停用当前选择时返回总览。历史分析保留停用 Agent 的查询能力。

macOS 与 Windows 按入口使用一致的右键菜单。桌宠菜单提供面板、设置、桌宠设置、检查更新和隐藏桌宠；菜单栏／托盘提供详情、设置、活动采样管理、检查更新、动态桌宠显隐和退出。更新复用现有安装与草稿保护流程；没有其他入口时不允许隐藏唯一桌宠。

## AGY 有效区间

AGY 各模型组和各窗口独立核验周期。未使用窗口的重置时间随查询移动，不再否决其他窗口的消耗。实际重置、额度回退、套餐变化和超过五分钟的快照缺口仍中断受影响的配对。第一次建立新周期基线不补猜用量。

零消耗快照延续对应窗口的待配对区间；计数增加后核验完整区间的模型归属、用量边界与价格。无法确认的区间跳过，已有有效值保留。状态说明区分缺少用量、边界不完整及周期变化。

## 滚动金额

### Codex 多账户联合估值

按机器与 Codex home 隔离保存创建者指纹、登录身份观测、明确切换边界及请求侧额度指纹。本机与 SSH 历史读取器使用同一归属核验；SSH 只传输创建者的用户／工作区组合哈希，不传输原始创建者标识或对话内容。

请求必须完整落在同一身份区间内；恢复旧会话允许使用账户与原始创建者不同，新建会话的创建者与使用区间冲突时跳过。应用内切换记录前后时刻，A→B→A 不合并成连续 A 区间；应用外变化按上次观测至本次观测之间的不确定范围处理。超过五分钟的观测缺口不补猜。未被观测且未留下请求侧额度差异的外部快速切换无法从现有日志完整重建，估值不等同于账户账单。

额度变化只校验同账户、套餐和重置周期的消耗，不按比例把共享成本分摊给账户。同一请求成本不会计入两个账户；API 用量继续排除，5h、7d 和 credits 分别配对。已知关联目录未完整纳入、且不能确认该目录当前使用其他账户时，等待完整目录用量。应用内切换后尝试补齐旧账户尾段；失败仍完成账户切换，封存已确认样本，新账户重新建立基线。

实时估值以当前启用的来源、机器和 Agent 范围为准。手动暂停的机器退出实时覆盖检查，前提是暂停期间不在这些机器上使用同一账户。仍启用但离线、采集失败、身份未知或未开启自动估值的关联目录继续执行完整性检查。范围变化会封存有效结果、重建基线；即使暂停和恢复发生在两次采样之间，也不拼接跨范围区间。历史恢复仍要求当时的身份与覆盖证据，不用当前暂停状态推断过去的设备使用情况。

估值界面保留最后有效金额和样本截止时间，同时按 `sources.autoValuationStatus` 显示当前采样或等待原因。计算依据分别列出当前参与来源和历史样本来源；开关开启不再代表采样正在持续产生有效结果。

新 Codex 自动片段的 `attributionVersion` 为 1，`attributionEvidence` 保留算法依据、额度起止时刻及配置指纹。旧自动样本的金额、价格和片段保留，标记 `rollingExcludedReason` 并退出当前汇总；新样本不会回退显示这些未确认金额。整个过程不改变共享事件的 Token 和账户标签，也不新增账户 Token 总量。

可运行 `python3 scripts/diagnose-codex-estimates.py /path/to/aieyes.sqlite --days 30` 生成只读脱敏报告。报告仅输出匿名账户／来源编号、采样状态、创建者与切换证据数量、额度消耗及样本成本，不打开凭据或对话文件。

仅汇总自动采样，手动采样保留原金额公式；Codex 共享目录的手动采样同样核验账户归属。有效片段按账户、套餐、模型组以及 5h／7d／credits 分开，纳入活动和封存记录。最近 90 天的片段按结束时间衰减，权重每七天减半：

```
w_i = 2 ^ (-(now - ended_at_i) / (7 * 86400))
额度价值 = 100 * sum(w_i * cost_i) / sum(w_i * consumed_percent_i)
1000 credits 价值 = 1000 * sum(w_i * cost_i) / sum(w_i * consumed_credits_i)
```

这是按消耗量和时间加权的成本比率，不直接平均各条估值。5h 和 7d 独立计算；7d 容量推算沿用历史容量倍率。片段保留原价格依据，重复、重叠、无效及已被修正记录替代的片段不重复计入。优先保留实时采样证据，其次使用历史恢复证据。缺少套餐证据的旧记录仍保留在历史中，不混入当前套餐汇总。金额为 API 等价价值，不是可兑换余额。

`dashboard`、`dashboard.summary` 和 `dashboard.status` 新增 `automaticEstimateSummaries`。条目复用估值金额字段，`samplingMode` 为 `rolling`，并提供 `sampleCount`、`lookbackDays: 90` 和 `halfLifeDays: 7`。此数组只用于展示，不冒充可停止／重启的采样记录。原有估值数组及查询接口保持兼容。

区间投影可以从原记录重建，按时间、账户建立索引；原记录变更后失效重建，汇总按数据版本和分钟缓存。

## 历史恢复与验证

开启 AGY 自动估值后，后台分批恢复最近 90 天已有快照与用量；每批约 250ms 后让出写锁，可中断、恢复及重复调用。实时基线与回放基线分开，恢复不改写原用量、价格、账户配置或旧采样。

诊断接口 `autoEstimates.rebuild({accountKey?, dryRun?})` 处理一批已授权来源，返回完成状态、观测数量、恢复区间及跳过原因。`dryRun: true` 回滚该批变更；重复调用至 `complete: true` 可完成回放。接口只读取已存证据，不连接远程主机或查询登录凭据。

验证包含 Rust 自动采样／滚动汇总回归、两种 Web 界面的四 GPU 和滚动估值展示、原生浅深色布局截图，以及真实数据库临时副本的回放、完整性和原数据不变校验。副本在检查结束后删除。Windows 原生窗口和右键菜单仍需 Windows 实机验收，macOS 宿主测试不替代该项。
