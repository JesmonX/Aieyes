## 续接时补充修复

- 修复 Tauri 路径处理的 Clippy 错误，更新旧回归以先展开服务器摘要再操作细项。
- 原生详情、今日面板和菜单栏查询完成后一起发布；任何辅助查询失败时保留完整上一结果及已应用口径。
- 原生保存并重算区分配置已保存与重算失败，保留待添加映射供重试；重复映射不静默覆盖。
- 修复服务器摘要继承旧样式造成的多余留白；未知 GPU 保持 `—`。
- 全账户弹层覆盖尚无快照的账户，刷新限额后就地更新 Web 弹层；热力图对话框关闭恢复日期焦点。
