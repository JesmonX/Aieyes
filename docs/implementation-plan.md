## 1. 接口验证

先取得每个 Provider 的脱敏记录样例与限额返回样例，记录工具版本、账号类型、字段单位、更新时间及查询方式。

首要问题：Codex Bank Reset 字段来源；Antigravity 能提供的历史粒度与限额窗口；Claude Code 的缓存统计口径；OpenRouter 的当前价格维度。

验收：每个目标字段都有已验证的数据来源，或被明确列为尚未接入；字段缺失不生成虚构数值。

## 2. macOS 首条完整链路

实现 Rust 核心进程、协议、SQLite 存储与 SwiftUI/AppKit 菜单栏。先打通一个已验证的本机 Codex 数据源：导入 → 归一化 → 最近 7 天统计 → 原生界面。

验收：运行真实数据；重复导入不增量翻倍；关闭窗口后菜单栏与任务正常工作；重启保留数据与配置。

## 3. 多 Provider、多账号与远程历史

加入 CC、AGY，完成主机/来源/账号管理、SSH 远程导入、账号限额，以及 Bank Reset 状态。完成应用代理与远程前置命令设置。

验收：同一账号的多来源限额不重复；跨来源复制日志可依据稳定身份去重；前置命令与查询共享环境；失败时保留上次真实数据与同步时间。

## 4. 统计与定价

实现热力图、模型占比、筛选、价格同步、手动模型映射、缓存价格与历史价格快照。

验收：用独立人工计算的样例核对总 Token、缓存命中率、模型占比和成本；覆盖计数包含/不包含缓存两种来源；缺价格不按零价计入；跨时区与夏令时分日正确。

## 5. Linux 服务器监控

实现 CPU、内存、NVIDIA GPU、文件系统、磁盘 I/O 与网络，支持指标组和设备级选择；完成采样存储与可见性驱动的刷新频率。

验收：至少在一台真实 Linux 服务器验证；覆盖无 GPU、多网卡、容器挂载、采样中断与计数归零；对照系统原始计数验证速率。

## 6. Windows/Linux 与分发

完成第二套桌面界面、托盘、平台凭据存储、打包与升级；核心与 macOS 共用相同的协议与样例。

验收：在每个目标系统实际启动安装包，检查托盘行为、休眠恢复、SSH、代理、统计一致性与更新。通过后再宣称该平台已支持。

## 必要验证清单

- Token 归一化：缓存重复计数、输出中的推理子集、累计快照差值。
- 导入：截断、轮转、重复事件、部分写入、来源迁移。
- 价格：不同单位、缺少缓存价格、模型别名、价格版本与重算。
- 时间：UTC 存储、本地自然日、夏令时、跨天重置。
- SSH：空格路径、环境变量、前置命令失败、超时、重连与退出。
- 指标：首个样本、计数回退、设备消失、同名设备更换、主机重启。
- 界面：键盘导航、VoiceOver、深浅色、长账号名、紧凑窗口与多显示器锚点。

UI 原型可以使用独立标记的样例数据；发布构建默认连接真实来源。
