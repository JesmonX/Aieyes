# 三端交互一致性与桌宠改进实施计划

状态：已完成实现与本机验收；目标系统验证边界见[验收记录](cross-platform-and-pet-implementation-2026-10-14.md)。用户于 2026-10-14 逐项确认并要求先写入 docs 再执行。实施基线 `5fb1c1e`（0.1.37）。

范围：macOS 原生客户端、Windows/Linux 共用 Web/Tauri 客户端及 Rust core。下列变更已获得确认，实施时不重复询问；新发现的产品或设计问题另行讨论后决定是否修改。验证使用隔离数据和模拟服务，不操作真实账户登录、SSH 部署或其他应用配置。

## 桌宠导入与库

1. 统一识别本地 ZIP/`.codex-pet.zip`/`pet.json`、ZIP 或 manifest 资源链接（包括没有 `.zip` 后缀的下载）、已适配站点页面、npx 命令、npm 包名及 scoped/version/tag 写法。
2. 只解析并下载素材，不执行安装器、包脚本或 npx，不依赖 Node.js。适配 `codex-pet.org`/`codex-pet-installer add <id>`、Petdex/`petdex install <id>`、CodexPets 下载；通用 npm tarball 包含标准 manifest 与图集时可用。未知纯脚本包明确提示提供资源链接，缺少 ID 或多个候选时不擅自选择。
3. 成功导入立即启用新桌宠并保留旧桌宠。库显示名称、已知来源/作者、idle 预览和“使用/使用中”。相同内容复用已有条目；同名不同内容并存，按日期/来源区分。
4. 选择持久化。恢复 Aieyes 自身全部可辨识有效旧缓存，保留当前选择；缺少元数据用“历史桌宠”与可辨识导入日期表示；损坏缓存逐项报告，不阻塞其他项。不扫描其他应用的宠物目录。
5. 库元数据与图像按需读取分离，仅可见预览播放，离屏或关闭时暂停，尊重减少动态效果。
6. 保留 Codex v1/v2 PNG/WebP 图集格式。clawd 原生 SVG/GIF/APNG 不在本次范围，v2 的额外 16 个视线格也不增加新行为。

### 数据与接口

- `pets.import` 增加自动识别的 `input`，兼容原 `path`。
- 新增 `pets.list`、`pets.select({libraryId})`、`pets.asset({libraryId})`。
- 库 ID 独立于原始 manifest ID；保存原 ID、内容 hash、导入时间和已知来源/作者。
- 图片完整写入后原子提交库记录与当前选择；失败/取消不替换当前桌宠。
- 网络获取与配置写队列分离，慢下载不阻塞设置保存。
- `PetState` 增加每帧时长，保留旧 `frameMs` 兼容字段。以 `docs/core-contracts.json` 为规范源，通过 `scripts/sync-core-contracts.py` 生成 Rust/Swift/JS 常量与接口声明。
- 远程前置命令沿用账户×机器的已有 schema。
- 实施中新增确认：同一账户×机器的多个历史目录存在不同前置命令时，清空冲突命令并提示重新设置；不自动挑选任一目录的命令。用户于 2026-10-14 明确选择此迁移方式。

## 动画节奏

采用已核对的基础分帧时长；当前会话动作持续循环，不采用播放三轮后回 idle。使用单调时钟，普通轮询/数量变化不重启动画；各端播放器与库预览共用同一时间定义。

| 行 | 动作 | 每帧毫秒 | 每轮毫秒 |
| --- | --- | --- | --- |
| 0 | idle / interrupted | 280, 110, 110, 140, 140, 320 | 1100 |
| 1 | running-right | 120, 120, 120, 120, 120, 120, 120, 220 | 1060 |
| 2 | running-left | 同上 | 1060 |
| 3 | waving | 140, 140, 140, 280 | 700 |
| 4 | jumping | 140, 140, 140, 140, 280 | 840 |
| 5 | failed | 140, 140, 140, 140, 140, 140, 140, 240 | 1220 |
| 6 | waiting | 150, 150, 150, 150, 150, 260 | 1010 |
| 7 | running/work | 120, 120, 120, 120, 120, 220 | 820 |
| 8 | review | 150, 150, 150, 150, 150, 280 | 1030 |

证据：本机官方 Codex `26.1007.30912`（20156）的 `app.asar`；[官方说明](https://learn.chatgpt.com/docs/pets)；[clawd Codex 适配器](https://github.com/rullerzhou-afk/clawd-on-desk/blob/c52e2df6ff778bf85310166882c516385f2f6eab/src/codex-pet-adapter.js)及相同提交的 `animation-cycle.js`。官方 idle 实际乘 6、默认非循环动作三轮后回慢 idle，均不是本次选择。只独立实现已核对的规则，不复制 clawd 的 AGPL 实现或素材。
