# Credits 估值与订阅定时唤醒

## 计价和额度采样

用量计价、7d 估值和 credits 估值共用普通输入、输出、缓存读取、缓存写入四类价格；推理 Token 已包含在输出中，不重复收费。任何有用量的维度缺价时，不输出完整额度估值。

Codex 卡片单独显示 credits 余额、无限额度状态和更新时间。不累加模型子额度池，也不与 Bank Reset 次数混用；查询失败保留上次成功数据，日志不会覆盖实时余额。

点击“估算 500 / 1000 credits 的 API 价值”，选择来源并确认本段仅消耗 credits、所有设备均已纳入，然后开始采样。建议新建会话，完成后点击结束。计算为：

`每 N credits 的 API 等价金额 = 样本 API 成本 × N / 实际消耗 credits`

N 同时取 500 和 1000。余额先做精确十进制相减；至少消耗 5 credits、计价完整且事件区间可归属才显示结果。明确 API 用量排除，重复来源不会重复计数。充值、订阅额度恢复、来源变化或查询失败后转为待确认，保留最后有效区间；可以结束保存，或确认开启新一段。结束后的价格依据固定。旧解析器造成的边界误判可在采样历史中选择“按原记录修复估值”，生成保留原记录的修正版，详见 [采样修复说明](sampling-repair-and-appearance.md)。

结果反映样本模型组合，不是可兑换余额。来源关联不能证明每次请求的实际扣费；未采集设备、混用包含额度或中转都会影响归因，因此必须由用户确认采样条件。

## 定时唤醒

在“设置 → 定时唤醒”中新增任务：

1. 选择已保存且关联订阅账户的数据源，位置由来源决定：本机或 SSH Linux 服务器。
2. 填写每天一个或多个 `HH:mm`，按目标机器时区执行。
3. 点击“读取模型与执行能力”，选择模型和 effort。对可列出的模型，按已有价格的 1,000 输入 + 100 输出 Token 参考成本推荐低价模型；支持时默认 low。
4. 保存草稿，然后点击“部署”。修改草稿后需“更新部署”才影响系统任务。

支持 Codex、Claude Code 和 agy 非交互调用，使用目标用户已有登录。Codex 探测订阅登录和模型列表，运行时强制 ChatGPT 登录方式；Claude 检查订阅登录，agy 检查订阅额度。无法核验模型列表或价格时需要手动填写模型，不声称已找到最便宜模型；Claude 当前使用这一手动选型方式。agy 当前仅支持目标用户默认登录目录。模型固定在部署配置中，不自动切换。

本机执行器随安装包提供，并复制到稳定数据目录；macOS 使用用户 LaunchAgent 和每分钟调度进程，Windows 使用任务计划程序，Linux 使用用户 crontab。SSH 目标使用 Python 3 标准库执行器和 crontab，无需安装 Aieyes。退出 Aieyes 后继续运行，本机 macOS/Windows 需用户保持登录；不会唤醒休眠电脑，离线或错过时刻不补发。

每次新建非交互会话，模型调用超时为 120 秒，不自动重试。同一分钟的不同账户并发执行，同一账户有运行任务时跳过；每日时刻持久化去重，时钟回拨不重复同一天的相同时刻。成功必须收到模型完成事件，不能只凭进程退出码。

管理页提供更新部署、启用、停用、立即运行、状态与最近 30 条记录、移除。停用阻止后续定时触发；“立即运行”仍可手动触发。已开始的调用可能继续到完成或超时。移除失败保留待移除记录；有关联部署时不能直接删除来源、账户或目标服务器。只管理 Aieyes 自己的系统任务，保留其他 cron 条目。

## 接口和数据

- `creditEstimates.start/stop/get/list/restart` 共用周额归因和计算机制；dashboard 增加 `creditEstimates`。
- `wakeups.save/list/probe/deploy/enable/disable/run/status/history/remove/delete`；草稿与部署配置分开保存。
- SQLite 新增 credits 采样表；旧快照和事件兼容。执行历史只保存状态、时刻、模型及 effort，不记录 CLI 输出或凭据。

## 验证范围

核心测试覆盖缓存成本一致、精确余额、充值暂停、额度恢复、价格冻结、日志与实时快照优先级、标准化窗口兼容、任务去重、跳过错过时刻及不同账户并发。Python 模拟测试覆盖远程部署回滚、重复移除、保留其他 cron 任务、同账户重叠和失败状态。测试使用隔离目录及假 CLI，不为真实账户部署或发起付费调用。

Web 回归覆盖 credits 开始/结束、模型推荐、草稿与部署分离、启停、历史和移除失败，已接入 `npm --prefix apps/desktop run test:ui`。原生截图入口包含 credits 和唤醒设置页，可使用 `scripts/preview-quota-core.py` 模拟数据渲染。

本轮在 macOS 运行核心、Tauri 宿主、Python、Web、Swift 回归和调试包构建。Windows/Linux 系统调度器、真实 SSH 部署和真实订阅模型调用仍需对应环境实测；模拟测试不等同于这些验收。
