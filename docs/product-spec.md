# 产品规格

这是最终产品目标；当前实现与验证状态见 [README](../README.md)。

## 已确认范围

- macOS 使用 SwiftUI/AppKit 原生菜单栏界面。
- Windows/Linux 复用数据核心，使用各自的托盘入口与桌面界面。
- Agent 首批接入 Codex、Claude Code（CC）、Google Antigravity（AGY）。
- 同时支持本机与 SSH 远程来源，支持多账号。
- SSH 服务器监控首先支持 Linux。
- 支持应用代理，以及远程查询前执行的可选前置命令。
- 应用文本不出现防御性表达。

## 入口与信息层级

菜单栏常驻项目可选：应用图标、指定账号的剩余额度、今日 Token、指定服务器的 CPU / 内存 / GPU 指标。建议默认只显示图标与一个用户选定的指标，控制横向占用。

点击打开原生面板，顶部切换「Agent」「服务器」，提供刷新、固定面板、打开详情与设置入口。面板保持紧凑；完整历史与管理操作进入独立原生窗口。

Agent 面板顺序：

1. 账户限额：按逻辑账户显示剩余额度、重置时间和 Bank Reset，同账户的多个来源共用一份状态。
2. 今日概览：总 Token、API 等价成本与缓存摘要；可切换历史范围。
3. 近 7 天模型堆叠趋势，展开查看逐日模型用量与缓存命中率。
4. 待计价模型入口与完整分析窗口入口。

服务器面板顺序：

1. 各主机连接状态与用户选择的概要指标。
2. 展开主机查看 CPU、内存、GPU、磁盘、网络。
3. 展开指标查看 CPU 核心、多张 GPU、挂载点、块设备、网卡。

## Agent 统计

| 项目 | 规格 |
| --- | --- |
| 默认范围 | 今日概览；趋势保留今天及前 6 个本地自然日，历史范围可切换 |
| Token | 总量、输入、输出、缓存读取、缓存写入；保留原始来源语义 |
| 分组与筛选 | Agent、账号、主机、模型；筛选同步作用于趋势、热力图、占比与成本 |
| 缓存命中率 | 缓存读取 Token / 全部输入 Token；先统一各来源口径，再按 Token 加权 |
| 热力图 | 默认最近 365 天，可切换年份；按 Token 或 API 等价成本着色 |
| 模型占比 | 环形饼图，按 Token 或 API 等价成本切换；提供数值列表 |
| 历史 | 增量导入可用的旧记录；持续归档新记录，保留模型原始名称 |
| 用量与限额 | 历史按来源采集；实时限额按账号与模型池采集，分别保存 |

缓存 Token 不重复计入总量。若来源的输入量已含缓存读取，则缓存是输入的子集；若来源把普通输入、缓存写入、缓存读取分列，则统一后相加。推理 Token 若属于输出的子集，只作为细分展示。

输入 Token 为零时，缓存命中率显示「—」。来源未提供的字段不推算成 0。

## 限额与 Codex Bank Reset

以来源返回的窗口长度、百分比、模型池和重置时间为准。Codex/CC 的 5h、7d 作为目标展示项；Antigravity 的窗口与模型池需核实实际数据后接入，不预设所有账号都有相同窗口。

同时展示绝对重置时间和相对倒计时，跨天时显示日期。倒计时到零触发刷新；只有来源确认后才更新额度状态。

账户独立于数据源管理；数据源也可以选择无账户／外接 API，不显示限额。多个本机账户分别关联各自记录目录。

同一账号可关联多个本机或远程来源。账号限额只保留一份逻辑状态，不随主机数量重复计算；每次快照记录查询位置与采集时间。

Codex Bank Reset 的确切字段与来源待核实。目标展示其可用状态，以及来源实际提供的剩余次数、补充或到期时间。不能从限额变化推断 Bank Reset 剩余次数。

用户已确认 Bank Reset 只查看状态，不包含手动使用入口。

## API 等价成本

价格优先取自 OpenRouter 模型目录，建立 Agent 模型名到 OpenRouter 模型 ID 的显式映射；支持手动选择映射、填写缺少的价格。

成本项分别覆盖普通输入、输出、缓存读取和缓存写入。具体字段、币种和单位须按实际返回数据确认后归一化。若有分层价格或不同缓存写入时长，分别保留计价维度。

归一化到每 Token 单价后的计算规则：

`成本 = 普通输入 × 输入单价 + 输出 × 输出单价 + 缓存读取 × 读取单价 + 缓存写入 × 写入单价`

不能把 OpenRouter 缺少的缓存单价当作 0 或直接套用普通输入单价。缺项时保留已计价金额与待计价 Token，并显示价格覆盖情况。

保存价格快照、抓取时间和生效区间。初次导入的历史记录若没有对应历史价格，明确记录采用的价格日期；默认不因后续价格刷新改写既有成本，可提供「按当前价格重算」。

面向用户的名称为「API 等价成本」，默认 USD；它是按 API 单价衡量的使用价值。订阅套餐费用可另行作为未来功能，避免混入 Token 计算公式。

## SSH 服务器监控

默认使用已有 SSH 配置与系统 SSH 客户端，支持密钥、ssh-agent、端口、跳板机、连接复用。首版目标为 Linux，无需安装常驻采集服务。

| 指标组 | 概要 | 可展开的细项 |
| --- | --- | --- |
| CPU | 总利用率、负载 | 每核、user/system/iowait/steal、逻辑核数、运行时长 |
| 内存 | 已用/总量 | available、缓存、buffer、swap |
| GPU | 利用率、显存 | 每卡、温度、功耗、名称；NVIDIA 首批，其他厂商按可用采集源扩展 |
| 文件系统 | 容量占用 | 各挂载点、可用空间、inode |
| 磁盘 I/O | 读写速率 | 各块设备吞吐、IOPS、繁忙时间 |
| 网络 | 上下行速率 | 各网卡、累计收发、错误与丢包 |

「磁盘容量」和「磁盘 I/O」分开；「即时网速」「采样期间流量」和「系统累计计数」分开。无连续采集时不声称掌握停采期间的历史。

允许逐台主机选择指标组，并在组内选择 CPU 核心、GPU、挂载点、磁盘或网卡。关闭的组尽量不执行对应采集。

建议刷新默认值：打开服务器面板时 3 秒，面板关闭时 30 秒，暂停主机不轮询；用户可修改。采样时间使用单调时钟计算速率，重启或计数器归零时重新建立基线。

## 代理与远程前置命令

分开配置以下三个环节：

1. 应用发出的 HTTP 请求：限额查询、价格同步、GitHub 更新；支持系统代理、直连、自定义 HTTP/HTTPS/SOCKS5，以及按来源覆盖。
2. SSH 连接路径：遵循 SSH 配置中的 ProxyJump / ProxyCommand。
3. 远程进程访问网络：每台主机可以设置工作目录、shell、环境变量和前置命令；可由具体 Agent 来源覆盖。

远程前置命令必须与查询在同一个 shell 会话执行，以便环境变量生效。前置命令非零退出时停止本次查询，保留执行状态；提供「测试连接」「测试查询」。

代理凭据与命令执行输出不写入普通诊断日志。前置命令由用户配置，应用不自动生成或执行改变远程系统的初始化步骤。

## 文案与状态

采用事实、时间和下一步操作表达状态，例如：

- 「上次同步 14:32」「正在同步」「连接失败 · 重试」
- 「尚无记录」「选择数据目录」「添加账号」
- 「待定价」「价格更新于 10 月 3 日」「已计价 92% Token」
- 「重置于 明天 08:00」「暂停监控」「已断开」

不使用免责声明或防御性提示。不把空值展示为零，不把演示数据混入真实统计。能力不适用的项目不放空白卡片；连接故障保留最近一次结果与时间。

## 尚需核实

- 三个 Agent 的实际用量记录格式、稳定去重标识、账号关联方式。
- Codex/CC/AGY 的当前限额读取途径、授权方式、返回字段。
- Codex Bank Reset 的准确数据源与返回字段；操作范围已确定为只读。
- OpenRouter 当前模型与缓存定价字段、历史价格可用性。
- 最低 macOS 版本与 Windows/Linux 发布优先级；建议 macOS 14 起步，并覆盖 Apple Silicon 与 Intel。

Codex 0.160.0 的本机日志与 App Server 生成协议已经核实，包含 Bank Reset。其余联网行为与 Antigravity 原生数据源尚未完成核实；以实现状态表区分目标能力和当前能力。
