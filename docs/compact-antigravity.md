## 采集与估值

`antigravity` 是统一 Agent；`agy` 是兼容输入别名，`agyBinary` 配置继续有效。设置只显示一个 Antigravity 选项。

默认读取 `~/.gemini/antigravity-cli/conversations/*.db`。本机 Rust 与 SSH Python 采集器从 `steps` 和 `gen_metadata` 提取统计字段，并在只读事务中包含已提交 WAL 记录。生成元数据支持打包／非打包步骤索引和两种模型字段；未完成调用不会提前计入。稳定调用 ID 用于更新和去重，本机游标同时检测数据库与 WAL 变化。

标准 JSONL 目录继续兼容。普通输入、缓存读取、缓存写入分别计价；推理 Token 作为输出子集，不重复累加。远端不返回会话正文。

额度通过 agy `/usage` 读取。Gemini 与 Claude/GPT 模型组独立统计成本、5h 价值、7d 同期值和容量倍率。每账户同时一段额度采样，窗口可选择模型组。未知模型／组、缺价或跨采样边界时保留原因并停止输出不可靠结果。旧账户总体采样仍可在分组详情查看，明确标为旧记录，不作为某一组的显示值。
