# 会话提示音

通知设置中，等待输入和任务完成分别提供启用开关、音色选择与试听。两类提示音共用 0–100% 音量；0% 静音，100% 使用原始音效音量，仍受系统输出音量影响。

| 音色 | 内容 |
| --- | --- |
| 经典 | 沿用等待输入、任务完成各自的原有音效。 |
| 清铃 | 短促的高音铃声。 |
| 和弦 | 依次展开的三音和弦。 |
| 木琴 | 两个有清晰起音的短音。 |
| 水滴 | 音高逐渐下降的短音。 |
| 电子 | 两段柔和的电子脉冲。 |

试听使用当前表单中的音色和音量，包括尚未自动保存的输入。关闭某一类自动提醒后仍可试听。静音或关闭提醒期间的事件会被正常记录，恢复时不补播旧事件；后台监测、同一状态去重与来源异常恢复规则保持不变。

配置保存在 `sessionSounds`，音量用 0–1 数值表示：

```json
{
  "needsInput": true,
  "complete": true,
  "needsInputTone": "bell",
  "completeTone": "marimba",
  "volume": 0.35
}
```

旧配置缺少新字段时使用经典音色和 100% 音量。未知音色回退经典，超出范围的音量限制到 0–1。音色目录由 `docs/core-contracts.json` 同步到 Rust、Web 和 Swift。

Windows/Linux 对内置 PCM 样本施加音量增益，macOS 使用 `NSSound.volume`。两者均不修改系统主音量。新增五款音效由 `scripts/generate-session-sounds.py` 合成，无外部音频素材；共享 CI 检查生成文件是否一致。
