# 三端 UI、控件与文案精简

本轮按已确认的 53 项计划调整 macOS 原生客户端和 Windows/Linux 共用的 Web/Tauri 界面。以布局、分组和状态表达用途，删除重复说明；必要的格式要求、操作后果和异常恢复入口保留。

本页记录 UI 精简阶段；后续的音量与音色扩展见[会话提示音](session-sounds.md)。

已确认的边界：服务器监控与机器配置分开；额度卡保留现有信息密度和展开偏好；专业配置按需展开；沿用现有账户、面板选择、保存和部署行为。官网、品牌素材、桌宠动画和 RPC/schema 不在本轮变更范围。

## 实现与兼容

- 保留现有页面标识、设置目的地参数、账户及机器身份、RPC 和持久化 schema。
- Web 的说明弹层归属于触发控件所在的对话框，避免模态窗口使弹层失去交互能力；Esc 关闭并恢复焦点。
- SwiftUI 的 `HelpNote` 独立为公共组件，桌宠等单独编译的视图也沿用同一实现。
- 复用设计变量与本地化生成流程。导航测试同步覆盖新的设置入口，业务测试通过实际展开操作访问专业配置。
- 测试使用合成数据和隔离配置，不登录用户账户、不部署真实 SSH 任务。

主要入口：Web 导航与帮助在 `index.html`、`app.js`、`workspace.css`；账户与专业配置在 `agent-settings.js`、`codex-api.js`、`wakeups.js`；原生对应 `MainWindowView.swift`、`SettingsView.swift`、`AgentSettingsViews.swift`、`Views.swift` 及各编辑视图。文案以 `locales/en.json` 为源，同步生成 Web/Swift 本地化目录。

回归中一并修复了语言切换重建表单时误触发自动保存的问题：渲染过程产生的 `change` 事件不提交尚未确认的输入，用户实际修改仍沿用自动保存。
