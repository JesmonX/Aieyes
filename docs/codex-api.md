# Codex API 接入

在「设置 → Agent 接入 → Codex → API 连接」选择**添加 API**，选择本机或已配置的 SSH 设备，填写 Base URL、API Key、模型和可选的推理强度。接口需兼容 Responses API。保存前读取目标配置版本；发生并发修改时保留草稿并要求重新读取，避免覆盖其他窗口的修改。

API Key 保存在目标设备的受管理目录，不进入公开设置和界面返回值。留空保留已有密钥；移除连接会删除对应设备密钥及受管理配置。每个连接可配置代理和按模型填写的 USD / 百万 Token 价格。远程代理支持 HTTP(S)。

保存会部署本机回环计量服务，并注册目标系统的后台任务，使退出 Aieyes 后仍可使用连接。应用内可以测试接口、检查服务状态、复制启动和续聊命令。没有注册成功或运行时缺失时会报告错误；部署失败会尝试恢复原有配置和任务。

API 与订阅使用同一个 Codex home 和对话历史。复制启动命令可单独启动 API 会话；设为默认只影响后续启动或恢复的会话，已有会话继续使用原方式。续聊前结束当前轮次，再执行续聊命令选择原对话。**切回订阅**恢复默认订阅入口，不改写共享登录凭证。

## 用量与费用

- **API 估算成本**使用请求级计量证据及该连接配置的模型价格；它不是服务商账单。
- **订阅 API 等价估值**使用能够归属为订阅的用量。API 用量不计入订阅估值；同一个 home 混用时，采样前需要明确确认归因范围。
- 未知来源、缺失计量、没有完整结束的请求及缺少价格会单独提示，不将缺失数据显示为完整计费结果。移除连接保留历史用量和费用记录。

## 验证

核心测试覆盖请求计量、订阅/API 归因隔离、并发配置冲突及部署回滚；`scripts/test-codex-api.py` 覆盖远程配置与计量。Web 回归覆盖管理入口、费用分项、失败草稿和混用确认，Swift 模型及原生构建覆盖同一接口。

`scripts/test-codex-api-cli.py <codex 路径>` 用实际安装的 CLI 连接本地模拟接口，验证同一对话在 API／订阅之间恢复、显式及默认连接切换、共享凭证保持和请求数。测试不调用真实收费接口，也不安装系统后台任务；真实服务商兼容性和远端长期运行需要在对应环境验收。
