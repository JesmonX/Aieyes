# 10-06 UI 改革实施与验收记录

依据 [改革方案](ui-reform-2026-10-06.md) 完成阶段 0–2 的代码实施，并将阶段 3 中可在当前 macOS 工作区执行的回归加入脚本。真实 Windows 桌面及辅助技术操作验收仍需对应环境；以下没有把截图或交叉类型检查等同于实机验收。

## 落地结果

| 原方案项 | 实施 |
| --- | --- |
| 1、破坏性操作 | macOS 数据源、服务器、账户归档使用确认 sheet，列出受影响关联项，初始焦点取消，红色确认；操作先改草稿，保存后提交。定时任务删除和移除部署也需确认。桌面归档补取消焦点与红色按钮。 |
| 2、11、刷新入口 | 两端主窗与面板统一四项菜单；每项有进行中、成功时间、失败状态。桌面外壳广播刷新状态，使两个窗口共享反馈；广播只包含动作、时间和错误条目。 |
| 3、菜单栏口径 | macOS 使用独立的无筛选、今日 dashboard；Token 与首账户限额不会跟随详情筛选。设置注明“今日全部 Token”，菜单栏 tooltip 标明口径。 |
| 4、按压反馈 | 移除全局按钮 transform 覆盖，静态卡片保持稳定，按钮恢复按压反馈并遵守减少动画设置。 |
| 5、面板页签 | 桌面采用 accent 选中底、对应前景色与加粗字，28px 分段控件。 |
| 6、空态 | 会话条先于引导；无用量时移除零值统计与图表。首次无来源时隐藏筛选；筛选造成空结果时保留筛选与“清除全部”，避免无法返回。有实际限额的账户继续展示有效限额。 |
| 7、时间语义 | 两端显示“数据时间 · 状态”，使用 dashboard 生成时间；服务器页使用采样时间。完成动作的成功时间仅显示在刷新菜单，失败不会冒充新数据时间。时间格式跟随系统区域设置。状态区可点击刷新。 |
| 8、卡片语言 | macOS 中性材质卡片与中性边框；去除统计卡彩色底和渐变描边。桌面中性卡片去除逐卡高光。颜色集中于数据、图标、进度和状态。 |
| 9、价格保存说明 | 两端注明价格条目及同步立即生效、映射随保存提交。桌面设置卡片原地显示已保存时间，失败保留配置并显示原因；macOS 保留草稿脏标记与关闭确认。 |
| 10、图标 | 桌面交互字符替换为共享 SVG；设置分区与原生同语义图标。热力图使用五级色块图例。 |
| 12、错误列表 | 两端按来源/账户/服务器展示原因与重试，限高滚动。重试携带 sourceId/accountId/hostId，并保留其他失败项及服务器已有采样。 |
| 13、限额标题 | 灰色计数、排序图标、统一“刷新限额”文案。折叠时保留窗口名称、剩余百分比与进度，隐藏重置时间和余额细节。 |
| 14、会话行 | 来源、短 ID、相对时间；说明转为 summary 提示。待确认会话、延迟数据、待确认采样及计价不足使用注意组件和对应动作。 |
| 15、通用设置 | 桌面连接与刷新合并为“网络与刷新”，一个保存按钮；未保存检查覆盖完整表单。 |
| 16、原生设置 | macOS 数据源、服务器、价格、唤醒、通用统一 grouped Form。 |
| 17、唤醒按钮 | 部署/更新部署为主操作，其余为次要操作，删除/移除为危险操作并展示影响确认。 |
| 18、估值窗口 | macOS 固定“账户名 · 额度估值”，口径继续在窗口内切换。 |
| 19、快捷键 | 桌面 Ctrl+, 设置、Ctrl+Shift+D 详情；面板对应按钮提示中标注快捷键。刷新菜单支持方向键、Home/End、Esc 与焦点返回。 |
| 20、提示气泡 | 键盘聚焦立即显示，指针保留延迟；最大宽度随窗口变化，保留原有 aria-describedby。 |
| 21、胶囊 | Windows 使用 SPI_GETHIGHCONTRAST 与系统窗口/文字颜色，响应主题及设置变化；原生保持静态、无呼吸动画。原生和 Web 字号为 13px。 |
| 22、Mica 标题栏 | Mica 时去除标题栏第二层背景；确认 Tauri 自带 drag-region 双击最大化，不叠加第二个切换处理器。 |
| 23、原生标题栏 | 详情与设置均使用透明标题栏。 |
| 24、面板密度 | 两端限额默认摘要，趋势默认折叠；尚无采样的估值操作在展开后显示。详情与面板统一缓存命中率和 Token 明细合并组件。 |
| 25、语言范围 | 本次保持既有中文产品范围；安装器系统语言不作为增加整套 i18n 的依据，未引入新的本地化依赖。 |

组件 token 对齐：卡片圆角 16、浮层 20、控件 9；正文 15、辅助 14、节标题 16、页标题 22。正常/注意/错误/accent 的浅深色值两端一致。macOS 材质组件覆盖减少透明度和增大对比度分支。

- `npm --prefix apps/desktop run test:ui`：原有浏览器交互、限额、估值、更新和唤醒用例，加上 `test-ui-reform.cjs` 的数据时间、逐项重试、空态恢复、保存反馈、快捷键及截图矩阵。
- `node scripts/test-desktop.mjs`：14 项桌面交互检查。
- `cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --offline`：19 项 Rust 外壳测试，含刷新事件字段范围及失败反馈。
- `sh scripts/test-native.sh`：原生模型、会话、代理、更新、credits 检查；新增无筛选菜单栏口径、失败数据时间、定向重试、删除影响与草稿回滚检查。
- `swift build --package-path apps/macos --scratch-path .build/swift --disable-sandbox`：原生应用编译通过。受限环境可加 `CLANG_MODULE_CACHE_PATH="$PWD/.build/swift-module-cache" SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/swift-module-cache"`，将模块缓存放在工作区。
- `sh scripts/check-native-capsule.sh`：真实 `capsule.rs` 使用 Windows bindings 与 Windows Rust target 进行类型检查。仅外壳胶水桩替代 Tauri，无 C 链接和运行时验证。
- `sh scripts/test-ui-native-render.sh`：用隔离的合成 RPC 数据运行原生 `--render`；数据状态包括空态、单账户、多账户、长名称、失败。截图覆盖浅深色、450×540、原生最小详情 760×480、设置小窗口、30 条映射及危险确认。
- `git diff --check` 与 Rust 格式检查通过。

截图输出：`.local/ui-reform-2026-10-06/desktop/`（28 张）与 `.local/ui-reform-2026-10-06/macos/`（194 张）。桌面包括 640×440、450×540、150%/200% DPI；原生包含材质组件的不透明/增强边框预览。所有截图使用合成数据，未读取个人日志、凭据或远程主机。

文字 token 对比度检查通过；中性卡片边框按浅深色选择可读颜色。已查看两端浅深色、低屏高与设置截图，修复折叠误隐藏额度标题等问题；桌面 450×540 下有关键数值位于 footer 上方的自动检查。模型图表色新增两端各 10,000 个模型名称的浅深色对比度检查，正文状态色要求 ≥ 4.5:1，模型图形要求 ≥ 3:1。测试使用明确的中性背景范围，不等同于任意系统材质背景上的逐像素验收。

## 本次独立复验与修复

独立复验时的结论：**可在当前机器执行的自动回归通过；完整验收尚未通过，当时未执行 git 推送、打标签或触发 Release。** Windows 实机及 macOS VoiceOver、多屏验收结果或可用环境缺失，原方案 4.6 的完整验收仍有待办项目。

本次从已有未提交改动开始复验，发现并修复：

1. `desktop:data-changed` 读取筛选后的 dashboard 时，会清空 `desktop:refresh-status` 广播的失败项，并可能把后续正在进行的刷新改为成功。现在数据失效通知只更新数据，动作反馈负责进行中、成功时间和逐项失败；新增失败来源被筛选隐藏、单项成功保留其他失败、较新刷新仍在进行的回归。
2. `desktop:hosts` 原先只更新面板，面板触发的采样不能同步到主窗。现在两个窗口均接收采样及失败事件，定向采样保留其他主机数据。
3. 浅色绿色保存反馈对比度约 2.98:1；部分 macOS 警告仍用系统橙色，深色错误文字在较亮卡片背景上也不足 4.5:1。统一使用经过验证的正常/注意/错误 token，并调整服务器图形状态色。
4. 模型图表固定亮度不适合两种主题。两端保留模型名称决定的色相，按主题调整亮度；桌面主题切换同时更新图表和图例。原生 `Palette` 拆为可单独验证的文件。

- 上述实机检查是阶段 3 的剩余验收条件，未标记为完成。
