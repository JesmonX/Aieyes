# 桌宠导入与选择

在「设置 → 常规 → 桌面显示」导入桌宠，或从桌宠右键菜单选择「桌宠设置」直接进入。首次离线加载默认月薪喵。

## 导入来源

文件按钮支持本地 ZIP、`.codex-pet.zip` 和 `pet.json`。文本输入会自动识别以下内容：

| 内容 | 支持方式 |
| --- | --- |
| ZIP 或 manifest 资源链接 | 按下载内容识别，不要求链接以 `.zip` 结尾；manifest 的相对图集地址按资源实际地址解析。 |
| codex-pet.org、Petdex、CodexPets 的单个宠物页面 | 读取已适配的资源下载地址。 |
| `npx codex-pet-installer add <ID>` | 按指定 ID 下载素材。 |
| `npx petdex install <ID>` | 按指定 ID 下载素材。 |
| npm 包名或 npx 包名 | 支持 scoped 包名、明确版本和 tag，例如 `@作者/包名@版本`；包内须含唯一标准 `pet.json` 及对应图集。 |

Aieyes 只解析输入并下载素材，不执行 npx、安装器或包脚本，也不需要 Node.js。只有脚本的未知安装器会提示改用资源链接；缺少宠物 ID 或包内有多个候选时需要提供明确的单个资源。

图集支持 Codex v1 的 8×9 和 v2 的 8×11 PNG/WebP，允许等比例缩放的单元格。v2 额外的视线格不增加新的动作；SVG、GIF、APNG 主题不在支持范围内。

## 选择与历史桌宠

成功导入会立即启用新桌宠，旧桌宠保留在库中。库显示名称、可取得的来源和作者、导入日期、idle 预览及「使用／使用中」。相同内容复用已有条目；同名但内容不同的桌宠并存，可按日期或来源区分。选择在重启后保留。

下载和图集校验完成后才提交库记录与当前选择；失败或提交前取消不会替换当前桌宠。下载使用独立通道，常规设置仍可保存。

升级时恢复 Aieyes 自身可辨识的有效旧缓存，并保留原选择。缺少名称等资料时标为「历史桌宠」，保留可辨识的导入日期；损坏项逐项提示，不阻塞其他条目。不扫描其他应用的宠物目录。

库元数据与图像按需读取，可见预览才播放，滚出视野或关闭页面后暂停；系统启用「减少动态效果」时显示静态帧。

## 动画与桌面操作

三端桌宠和库预览使用同一逐帧时间定义：idle 每轮 1.1 秒，工作动作每轮 0.82 秒，各动作保留尾帧停顿。动画使用单调时钟，普通状态轮询和会话数量改变不会重新从首帧开始；当前会话动作持续循环。「已中断」使用 idle 动画，状态文字继续显示「已中断」。完整逐帧表位于[实施计划](cross-platform-and-pet-plan-2026-10-14.md#动画节奏)。

右键菜单提供「设置」及「桌宠设置」。拖动松手后，距显示器工作区边缘 48 逻辑像素内吸附；macOS 不新增重置入口，Windows/Linux 保留已有重置位置功能。

## 接口

- `pets.import({input})` 自动识别输入，兼容原 `path` 参数。
- `pets.list` 返回库元数据、当前选择及恢复问题；`pets.select({libraryId})` 切换并持久化选择。
- `pets.asset({libraryId})` 按需读取图集；`pets.current({includeImage})` 继续兼容当前桌宠读取。
- `libraryId` 独立于作者的 manifest ID，记录保留原始 ID、内容指纹、导入时间及已知来源／作者。
- `PetState.frameDurationsMs` 提供每帧时长，旧 `frameMs` 字段保留兼容。共享定义以 `core-contracts.json` 为规范源。
