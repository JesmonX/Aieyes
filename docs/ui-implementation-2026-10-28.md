### Agent 移除与恢复

移除入口会暂停该 Agent 的采集，不删除数据源、机器选择、账户、凭据、历史或任务；重新添加时恢复原机器选择。首次添加且没有已选机器时保持停用。原本暂停的数据源不会因重新添加被强行开启。隐藏 Agent 的深链接仍可打开对应设置，不自动把它添加回入口或开启采集。

### macOS 原生改造

- 主窗口改用原生 `NavigationSplitView` / `List`，收起时保留约 62pt 图标栏；详情视图持续保留，切页不销毁页面身份。窗口采用全尺寸内容视图，标题为“当前页 — Aieyes”。
- M-14 使用一个菜单栏图形位置：空闲或无会话时为模板眼睛，其他阶段使用原阶段符号，保留颜色、脉冲和尺寸规则。去掉额外采样图标、菜单栏会话计数及其 macOS 设置；用量文本、提示和采样管理保留。Windows/Linux 的会话计数不变。
- M-16 标签最小 11pt，并按实际文字测量高度；逐帧缓存透明度蒙版，透明像素不接收输入，拖动期间保留捕获。默认开启同屏全屏时隐藏，退出后恢复，手动关闭桌宠优先。提示音规则保持原样。

### Linux 原生改造

- 实际 GDK 后端为 Wayland 时，主窗口保持原生 Wayland，桌宠与面板使用单独 X11 辅助进程；只有辅助进程设置 `GDK_BACKEND=x11`。X11 会话继续同进程运行。
- 主进程独占核心连接、托盘、轮询和偏好写入。私有 0700 目录中的 Unix socket 转发控制、事件及 RPC，带连接代次、消息大小与待处理请求上限；旧代次不能回写。父连接断开后辅助进程退出，崩溃只自动重启一次，再次失败返回主窗口。
- 系统主题通过 GTK 启动偏好与桌面 portal 更新；字体缓存按内容哈希复用，私有 fontconfig 不覆盖全局 GTK 字号。
- 桌宠逐帧更新输入形状，无合成器时同时设置可见形状；窗口管理器接管拖动后轮询释放状态并执行贴边。
- 外部 URL 启动解除请求进程组与 `GDK_BACKEND` 继承，不等待浏览器生命周期。托盘模式没有可用图标坐标时，面板使用工作区边缘锚点。
- 保存主窗口逻辑尺寸、最大化状态及 X11 位置；恢复时按剩余显示器工作区限制，Wayland 位置交给合成器。首次关闭提示继续后台监测；没有可用悬浮入口时不把主窗口藏掉。

macOS 离屏位图快照会漏画系统侧栏图层。本轮另外使用屏幕窗口截图确认原生 List 和折叠栏，并运行原生导航控件测试；没有把离屏快照中的空侧栏记为产品缺陷。
